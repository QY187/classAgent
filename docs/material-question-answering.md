# 课件解析与问答

## 使用方式

1. 在课程详情的“课程公共资料”或对应课次资料区上传文件。新文件自动解析，旧文件点击“加入问答”；失败可“重试解析”。
2. 状态变为“可用于问答”后，可在全局搜索中选择课件正文，或在主对话、课程对话及课次对话里提问，例如“只根据课件解释二叉树”。
3. 展开回答依据，点击文件与页码/幻灯片/段落查看原文。课次对话只读取本课次课件；课程公共资料请在课程对话中提问。

## 后台处理基础

课件沿用原上传与存储入口，原文件先保存，再登记 `material_processing` 任务。支持文字型 PDF、PPTX、DOCX、TXT、Markdown；图片和旧版 Office 仍可保留、预览或下载，不会显示为可用于问答。扫描 PDF 没有可提取文字时提示暂不支持 OCR。图片、图表及复杂公式的含义不作识别承诺。

PDF 保留物理页码，PPTX 保留幻灯片展示顺序；DOCX、文本按段落定位。每文件最多 2000 页/幻灯片/段落、100 万字，Office XML 解压内容最多 32 MB，保留原上传 25 MB 限制。超限明确失败，不静默截断为完整资料。

`material_processing` 和 `material_chunks` 为新增独立表，由既有启动建表流程创建。处理状态为 stored（存量未处理）、queued、processing、indexing、ready、failed、unsupported；文件存储状态仍独立保留。

上传自动提交后台任务；`POST /courses/{course_id}/materials/{material_id}/index` 用于存量资料补建与失败重试，返回 202。活动任务不重复登记。队列不可用时保留数据库登记，beat 每分钟最多补投递 50 项；超过十分钟未结束的处理中任务换代重投。worker 软/硬时间限制为 240/270 秒。

任务先原子认领 generation，再解析和向量化，最后在同一事务切换 active_version 和内容块。失败保留上一可用版本；旧任务不能覆盖新任务。错误信息不暴露供应商异常。文件、课程或所属课次在回收站时，内容与处理记录均不可读取；彻底删除依赖数据库外键级联清理。

## 搜索与原文页面

全局搜索增加 `kind=materials`，查询当前活动版本的课件正文，结果携带文件、位置和版本。权限先限定当前用户、课程和可选课次；课程公共资料不会进入单课次搜索。回收站记录及非活动版本不参与查询。

`GET /courses/{course_id}/materials/{material_id}/content` 按 offset/limit 分页读取活动版本，支持传入引用版本并返回 source_status=current/changed。页面 `/courses/{courseId}/materials/{materialId}` 显示提取原文、分页、版本变化提示和原文件预览；PDF 和幻灯片来源跳转使用实际位置，Word 采用提取段落定位。

课程页面增加公共课件上传区，各课次上传区保留。资料列表显示解析阶段、错误、旧版本可用提示和“加入问答/重试解析”，处理中定时刷新。存量资料不会启动时自动批量调用付费向量服务，由用户逐份点击“加入问答”。

## Agent 与引用

主对话、课程对话和课次对话共用课件读取能力。新增只读工具 `list_materials` 和 `get_material_content`，后者支持页/段编号与 offset 分页；文件目录可通过 catalog.material_ids 选择本轮实际查到的文件，名称与处理状态由后端重新核验。

`search_course` 默认 source_type=all，统一召回课堂与课件，复用 BM25、向量召回、RRF 融合与重排。可指定 material_id 或 source_type=material/transcript。当前轮语义规划保存来源限定到服务端上下文，工具和最终证据核验均受该限定约束，不能通过其他读取绕过。课次绑定严格限定本课次，不自动包含课程公共课件。

课件证据仅从本轮真实读到的文字建立，发布前重新核对可见性、文件归属、活动版本和文字快照。课件引用有 source_type=material、material_id、chunk_id、version、position、locator_type/number/label；不伪造录音时间。原有录音引用结构继续兼容。综合回答接收真实来源元数据，明确区分课件内容和课堂原话；两者矛盾时分别说明。

历史消息不改写正文；读取时重新验证课件引用。删除后标记 unavailable 并禁用跳转，换版后标记 changed 并允许打开当前资料核对。SSE、停止预览和消息保存沿用既有流程；重放同一请求不重新调用模型。

首版不改变纪要、复习卡片和小测来源。明确只根据课件出题时拒绝当前出题工具，不能偷偷用课堂录音替代。

## 验证

`tests/test_material_indexing.py` 覆盖文本/Office 定位、实际 PDF 文字页、空白及加密 PDF、PPT 展示顺序、队列失败后登记保留、重复执行、超时补投递、失效旧任务、重建失败保留旧版以及回收站过滤；`test_materials.py` 验证原文件流程兼容。网络向量化边界使用模拟，不涉及真实用户资料或线上操作。

搜索补充当前版本过滤、跨用户/课次隔离、课程公共资料范围、回收与恢复、来源位置和版本变化测试。

`test_agent_materials.py` 覆盖课件工具权限与分页、来源限定、真实证据与伪造版本、换版失效、混合检索词法降级、无转写课程问答，以及完整 HTTP/SSE 规划、读取、综合、核验、历史持久化与幂等链路。上游模型网络使用模拟，未进行真实供应商付费质量评测。

前端 `material-citations.test.mjs` 覆盖录音/课件混合引用、版本位置链接、HTML 转义和失效来源。浏览器验收使用隔离数据验证 1440px 和 390px 下课程重试、公共上传入口、搜索跳转、来源换版及聊天引用，报告位于忽略目录 `test-results/materials-20261108/`。

## 发布注意事项

按 `production-deployment.md` 发布受影响服务。本次新增后端依赖 pypdf==7.0.0，不能只复制 app 代码并沿用未安装该依赖的 Python 环境；API/worker/beat 更新同版后端，前端需重新构建。新增两张表由 API 启动 create_all 创建，不批量修改原课件或触发存量向量调用。建议上线时核对新表、一次实际课件解析及带引用问答，再检查原音频链路。当前本地未进行生产部署。
