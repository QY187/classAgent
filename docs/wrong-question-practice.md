# 错题连续重练

## 使用流程

1. 左侧进入“错题本”，按课程和巩固状态筛选。
2. 勾选需要练习的题，或者“选中当前筛选结果”。该操作选择全部筛选结果，不限于当前已展开的前 20 道题。
3. 点击“开始重练”，按列表顺序逐题作答。提交后才显示正确答案、解析和课堂依据。
4. 查看反馈后进入下一题，最后点击“完成本轮”查看汇总。
5. 汇总中可以展开每题的答案和依据，并选择“重练本轮错题”。新一轮只包含上一轮答错的题，统计重新开始。

切换课程或巩固状态会清空选题；“仅看已选”便于核对本次选择。

## 状态和保存规则

- 每次提交复用 `POST /wrong-questions/{question_id}/retries`，独立保存到现有 `quiz_question_retries` 表。
- 答对后进入“已巩固”，答错后保留或回到“待巩固”；原课堂小测分数与答题记录不改动。
- 每题成功提交后立即保存。提前结束会展示已答和未答数量，未提交的题保持原状态。
- 提交期间禁止重复提交和结束练习；请求失败时保留当前选项，用户可重试，未收到结果不能进入下一题。
- 本轮题目与汇总保存在当前页面内存中，刷新或离开页面后不恢复本轮进度；已成功提交的逐题结果仍然保留。

## 模块边界

- 错题本页面：课程和状态筛选、勾选题目、启动练习、同步题目状态。
- `WrongQuestionPractice`：逐题选择和提交、下一题、提前结束。
- `WrongPracticeSummary`：本轮统计、逐题结果展开、发起本轮错题再练。
- 判分、用户隔离和持久化继续使用已有后端，不增加数据库表或批量判分接口。

## 验证

前端生产构建通过。本地临时题验收了三题连续作答、两对一错汇总、只重练错题、刷新后巩固状态保留，以及提前结束时未答题状态不变。核对数据库确认五次重练记录独立保存，原小测仍为 0/3；验收课程及其关联测试数据已清理。
