## 全局模糊搜索

- 顶部快捷搜索和全局搜索页支持课程名称、学期、课次、文字记录、纪要、知识点及课件正文匹配。
- 支持部分名称、中文简写和空格分隔的多个关键词；例如“数构”可匹配“数据结构”。中文简写按字符顺序匹配，多个关键词取交集。
- 调整命中高亮与摘要位置，增加搜索失败提示及重试入口，限制关键词长度。
- 保留用户归属和课程范围过滤，SQL 通配符按普通字符处理。
- 不包含错别字纠正或语义同义词扩展。

## 学期与课程表

- 侧栏新增“我的课程表”，支持学期和排课的创建、编辑、删除、切换及设置首页学期。
- 用户设置学期起始日期和周数，起始日及之后六天为第一周，每七天递增；当前日期按北京时间计算。
- 支持教师、教室、课程关联、星期、节次、有效周次及单双周设置；实际生效时间重叠时阻止保存。
- 默认学校作息为五大节、十三小节，小节四十五分钟，同一大节内休息五分钟。

| 大节 | 小节数 | 时间 |
| --- | --- | --- |
| 第一大节 | 3 | 08:00—10:25 |
| 第二大节 | 2 | 10:40—12:15 |
| 第三大节 | 2 | 14:00—15:35 |
| 第四大节 | 3 | 15:50—18:15 |
| 第五大节 | 3 | 19:00—21:25 |

- 周视图包含月份、日号、星期、今天标识、上一周、下一周及回到本周。
- 格子大小固定，三小节与两小节的大节高度比例为 3∶2，课程数量及名称长短不撑大格子。
- 按学期统一分配鲜明配色，同一关联课程或未关联的同名课程跨天、跨周保持同色，不同课程分配不同色值。
- 学期和排课按用户隔离；调整学期后会导致已有排课越界时拒绝保存。

## 教务课表导入

- 支持文字型 PDF 及 CSV 文件，PDF 解析使用 pdfplumber；扫描图片型 PDF 暂不支持 OCR。
- 提供解析预览、原文核对、逐条编辑、选择导入、重复跳过及冲突提示。
- 支持表格、合并单元格、课程清单、单双周及不连续周次等已覆盖版式。
- 预览不写入数据库；确认导入后整批保存，发生冲突时整批回滚。
- 限制文件大小、页数和解析条目数；文件在本地内存解析，不调用外部模型。
- 尚未取得学校真实脱敏 PDF，实际教务版式仍需样例核对，不能保证任意 PDF 均能正确识别。

## 首页布局

- 左侧为收窄的本周课表，课表头右侧放置“导入课表”和“编辑课表”入口。
- 右侧显示紧凑的课程总数、待处理课次、最近学习、今日课程和常用功能。
- 今日课程按实际当前周读取，不随用户手动浏览其他周次切换；页面重新可见、获得焦点及定时刷新时更新。
