# 课程对话接入 Agent

## 读取工具与回答

问答工作台中的整门课程对话使用已有 Agent 循环。后端从对话记录绑定当前课程，不接受模型修改范围；`list_courses` 只返回当前课程，其余课次、纪要、原文与关键词检索工具都检查所属课程。即使另一门课程也属于当前账号，当前课程对话也不能访问它；跨课程查询应进入主对话。

课程对话复用主对话的工具进度、引用校验、历史保存、停止与重试。课堂结论必须引用本次实际读取且仍可见的原文，来源链接保留课次及录音时间点。已有对话及消息不需要迁移；课程回收后不能继续保存回答。

旧课次对话保留原 RAG 和仅本课次范围，不扩大历史范围。

## 课程内生成小测

用户明确要求生成小测时，课程对话开放已有 `generate_quiz` 工具。当前课程由后端绑定并传入提示词，未指定课次时默认整门课程；指定课次时先查询定位，有歧义再澄清。课次数量、题数及题型继续遵循原小测规则。普通提问、否定请求和询问如何生成不会开放写工具。

工具执行前检查当前课程范围，生成业务写入前再次检查对话归属、生成令牌、课程绑定、课次归属及原文内容。即使其他课程属于同一个账号，也不能在当前课程对话中生成其他课程的小测。若用户明确指定其他课程，模型应提示进入主对话或对应课程对话，不擅自替换课程。

课程对话复用原问题编号对应一组小测的幂等规则，结果卡片与主对话一致，仅显示名称、实际题数、范围和答题入口，不展示题干、答案或解析。题目保存到当前课程的小测历史，点击“开始答题”进入已有答题页，提交后才显示答案及来源；对话删除不删除题目，课程或课次回收时遵循原可见性规则。

历史中曾讨论某节课不会自动成为新请求的课次限制，只有明确指定或承接课次时才限定范围。历史中的“已生成”也不能代替本次执行；新问题需要实际调用生成工具，直接模仿历史成功回复会被后端拒绝，原问题可重试且不会增加虚构的小测卡片。

## 验证

新增集成测试覆盖课程绑定、已有历史与引用保存、步骤刷新、请求幂等、同账号跨课程与跨用户拒绝、工具失败恢复、停止后禁止保存及生成途中回收。原主对话和旧课次行为继续通过回归测试。

51 项相关后端测试通过。本地真实课程对话查询第二讲中的叶子节点数量关系，自动完成课次查询、纪要读取、关键词搜索与原文读取四个步骤，返回 11 条原文引用。刷新后步骤、回答及带时间点的来源链接均保留。

接入生成后，76 项相关后端测试通过，包括默认课程不重复查询目录、指定课次与范围澄清、其他课程拒绝、连续请求与失败重试、课程回收恢复、来源课次移到其他课程、停止前禁止保存以及答案隔离。前端类型检查与生产构建通过。本地真实模型生成三道判断题，连续生成的新请求保存独立小测，未指定课次时卡片显示整门课程；答题页确认三道判断题且提交前未展示答案解析。验证对话和小测保留供用户试用。
