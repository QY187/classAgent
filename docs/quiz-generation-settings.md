# 课堂小测出题设置

## 使用方式

在课程的“课堂小测”页面生成题目时，可以分别选择：

- 题目数量：5、10、15 道，默认 5 道。
- 题型：单选与判断混合、仅单选、仅判断，默认混合。
- 出题范围：整门课程或指定课次。指定课次支持搜索与多选，最多 50 节；搜索不会清除已选项，“选中搜索结果”会追加选择。

从课次入口进入小测页时，会默认选择该课次。历史小测会显示生成时选择的课次范围，旧的单课次小测仍正常显示。

## 来源与质量限制

当前使用课堂文字记录作为来源，课件文字尚未参与出题。所选课次都需要有非空文字记录，总计至少三段。不同课程、已删除或不存在的课次不能加入范围。

题数是目标数量。后端继续检查题型、选项、重复题目及课堂引用；引用无法核对的题目会被剔除，因此实际数量可能少于目标。有效题不足三道或混合题缺少一种题型时，返回生成失败，不保存不符合要求的题组。通过程序检查不代表答案绝对正确，可在提交后的结果页核对答案与课堂来源。

每题保留其原始课次与文字记录引用。多个课次的文字记录较多时，采样会兼顾所选课次，避免较短课次被完全遗漏。

## 作答流程

- 生成完成后直接进入答题页，展示题干和选项，不再要求用户编辑或核对草稿。
- 作答接口不返回正确答案、解析、原文摘录和原文跳转信息，避免提前提示答案。
- 全部题目作答后才能提交。提交后的成绩页展示正确答案、解析与课堂来源，答错的题目仍归入错题本。
- 已有草稿也可以直接答题；提交有效答案时转为 `ready`，不改动题目或已有成绩。未完成或无效作答不会改变状态。
- 再次答题时仍隐藏答案；此前成绩可以从“历史成绩”查看。

## 接口与存储

`POST /courses/{course_id}/quizzes` 增加 `question_type` 与 `lesson_ids`，保留旧的 `lesson_id` 参数兼容单课次调用。两种课次参数不能同时指定；不指定课次表示整门课程。

`quizzes.lesson_ids_json` 保存指定的课次列表，启动时通过幂等迁移补充列。旧记录为空时，读取原有 `lesson_id`。该变更不新增数据表，也不改写旧小测题目或作答记录。

新生成的小测直接保存为 `ready`，移除草稿题目编辑接口。保留旧发布接口兼容旧调用，但发布也不返回答案或来源；答案与来源通过作答结果接口提供。

## 验证

- 后端 11 项小测测试通过，覆盖题数、题型、范围校验、跨课程隔离、短课次采样、旧数据库迁移、作答前答案及来源隐藏、提交后展示、旧草稿兼容及错题归集。
- 前端生产构建通过。
- 本地页面验证数量与题型切换、多课次选择、搜索保留与追加选择、清空后禁用生成按钮。
