# 课堂小测出题设置

当前状态补充（2026-11-25）：课件解析、检索、替换和课件出题已于 2026-11-21 部署，后续版本继续保留。下方带日期的本地验证及“未部署”表述是历史记录，实际版本与线上验证范围见 [生产部署记录](production-deployment.md)。课表导入的本地 OCR 是独立入口，不能用于推断普通扫描课件已支持 OCR 问答。

## 使用方式

在课程的“课堂小测”页面生成题目时，可以分别选择：

- 题目数量：5、10、15 道，默认 5 道。
- 题型：单选与判断混合、仅单选、仅判断，默认混合。
- 出题范围：整门课程或指定课次。指定课次支持搜索与多选，最多 50 节；搜索不会清除已选项，“选中搜索结果”会追加选择。

从课次入口进入小测页时，会默认选择该课次。历史小测会显示生成时选择的课次范围，旧的单课次小测仍正常显示。

## 来源与质量限制

默认使用课堂文字记录，也可选择已解析课件出题。以下三段最低限制仅适用于课堂记录；课件使用选定文件的活动解析版本。所选课次都需要有非空文字记录，总计至少三段。不同课程、已删除或不存在的课次不能加入范围。

题数是目标数量。后端继续检查题型、选项、重复题目及课堂引用；引用无法核对的题目会被剔除，因此实际数量可能少于目标。有效题不足三道或混合题缺少一种题型时，返回生成失败，不保存不符合要求的题组。通过程序检查不代表答案绝对正确，可在提交后的结果页核对答案与课堂来源。

每题保留其原始课次与文字记录引用。多个课次的文字记录较多时，采样会兼顾所选课次，避免较短课次被完全遗漏。

## 作答流程

- 生成完成后直接进入答题页，展示题干和选项，不再要求用户编辑或核对草稿。
- 作答接口不返回正确答案、解析、原文摘录和原文跳转信息，避免提前提示答案。
- 全部题目作答后才能提交。提交后的成绩页展示正确答案、解析与课堂来源，答错的题目仍归入错题本。
- 已有草稿也可以直接答题；提交有效答案时转为 `ready`，不改动题目或已有成绩。未完成或无效作答不会改变状态。
- 再次答题时仍隐藏答案；此前成绩可以从“历史成绩”查看。

## 接口与存储

`POST /courses/{course_id}/quizzes` 增加 `question_type` 与 `lesson_ids`，保留旧的 `lesson_id` 参数兼容单课次调用。两种课次参数不能同时指定；不指定课次表示整门课程。

`quizzes.lesson_ids_json` 保存指定的课次列表，启动时通过幂等迁移补充列。旧记录为空时，读取原有 `lesson_id`。该变更不新增数据表，也不改写旧小测题目或作答记录。

新生成的小测直接保存为 `ready`，移除草稿题目编辑接口。保留旧发布接口兼容旧调用，但发布也不返回答案或来源；答案与来源通过作答结果接口提供。

## 出题覆盖与补题（2026-11-21）

课堂原文按1000字窗口、100字重叠分窗，不再仅使用各段开头350字。按课次均衡选取最多90个窗口，最多6批生成，提示模型覆盖不同概念与例子；不保证覆盖全部主题。跨批对题干做全半角与标点归一化去重，最多追加两轮补题并告知已有题干。调用受原有用户额度约束，失败不写入题组；原文不足或模型重复时仍可能少于目标数量。长课次仍为有界均匀采样，不代表全文无遗漏。

## 独立答案核验（2026-11-21）

每批候选通过结构和原文摘录检查后，使用独立模型上下文重新求解并核验唯一答案、引用支持和解析。审核缺项、重复编号、答案不一致或有歧义的题目不放行，过滤后进入上述有界补题。审核调用纳入Token额度与追踪，审核服务失败时整组不保存，不降级为未审核出题。该流程会增加模型调用成本和等待时间；独立上下文仍使用同一供应商模型，不构成正确性保证。

## 课件小测接入（2026-11-21，本地待验收）

课程小测页可选择课堂记录或已解析课件，课件支持按课程/指定课次和文件多选；仅使用当前活动解析版本，不读取扫描图像。Agent可根据课件出题，指定文件需先唯一定位，并由后端核对文件名及范围。课件题复用分窗出题、补题和独立答案审核。

作答前隐藏正确答案和引用；提交后显示文件名、页码/幻灯片/段落与原文跳转，错题可重做。保存前检查来源是否仍有效；已替换、删除或回收的来源不写入新题组，历史结果保留出题时快照并标明变更/不可用，不再跳转旧引用。课件错题暂不转为课堂知识点卡片，也不纳入依赖课堂片段的薄弱点生成，可直接在错题本重练。

新增 `quiz_questions.source_material_json` 可空字段保存引用快照，启动时幂等补列；旧题保持转写来源。API新增 `source_type=transcript/material` 和可选 `material_ids`，默认保持课堂记录。同步生成与审核共享150秒预算，最多6批加2轮补题；时间或有效内容不足时可能返回少量题，仍须至少3题并满足题型要求，否则失败不保存。页面等待175秒，沿用180秒代理窗口。

本轮未部署，不表示线上已提供课件出题。
