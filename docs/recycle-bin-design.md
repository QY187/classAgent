# 回收站模块说明

## 用户操作

- 课程、课次和上传资料的普通删除改为移入回收站；原文件和派生记录保留。
- 回收站支持按类型筛选、按名称和归属搜索、恢复及逐项彻底删除。
- 默认保留 30 天，从移入回收站的删除时间起算，到期不能恢复，由后台自动彻底删除。
- 此功能上线之前已经从数据库和存储中物理删除的数据不能凭回收站找回。

## 模块边界

| 模块 | 职责 | 不负责的工作 |
| --- | --- | --- |
| `core/visibility.py` | 正常查询排除回收站对象及其子内容；可见性查询避免身份缓存绕过 | 改变删除状态、文件清理 |
| `recycle_bin/migrations.py` | 为已有数据库补齐删除时间字段 | 业务操作 |
| `recycle_bin/mapper.py` | 原始对象读取、账号归属检查、课程到对象的加锁顺序 | 列表展示、恢复、清理 |
| `recycle_bin/service.py` | 检查处理状态，设置删除时间 | 永久删除、恢复 |
| `recycle_bin/queries.py` | 查询回收站列表，按父级合并显示 | 状态写入 |
| `recycle_bin/restore.py` | 只撤销目标对象的删除标记 | 文件搬运、重新生成内容 |
| `recycle_bin/purge.py` | 永久删除数据库内容，同时登记文件清理任务 | 文件清理的重试策略 |
| `recycle_bin/retention.py` | 三十天到期计算与判断 | 数据删除、定时调度 |
| `recycle_bin/expiration.py` | 锁后重新检查到期状态、调用永久删除事务、重试待清理文件 | 页面交互、调度器运行 |
| `recycle_bin/file_cleanup.py` | 执行待清理任务，失败保留记录，按账号重试 | 恢复和业务内容删除 |
| 页面及条目组件 | 列表、筛选、恢复交互 | 永久删除确认和文件重试内部状态 |
| `PermanentDeleteDialog`、`RecycleBinPurge` | 永久删除的独立确认和提交 | 列表查询、恢复 |
| `PendingFileCleanup` | 文件清理状态与重试入口 | 回收站项目管理 |

现有课程、课次和资料模块保留删除接口，交给回收站移入服务。其他业务模块使用统一可见性规则，无需复制回收站条件。维护接口显式开启 `include_deleted`，并再次校验账号归属。

## 数据与恢复规则

课程、课次和资料表分别新增可空的 `deleted_at`。未删除时为空，删除时记录时间。子内容无需跟随父级批量写入删除标记。

1. 删除课程后，正常查询隐藏该课程的课次、文件、文字记录、纪要、知识点、检索切片和小测记录。
2. 回收站只显示已删除的最高父级，避免课程和它的子项重复出现。
3. 恢复父级不会撤销子级之前的独立删除标记。独立删除的子项将在父级恢复后重新出现在回收站。
4. 恢复保持原 ID、归属、课次排序和文件位置，无需再次转写或重新生成纪要。
5. 处理中的课次，包括排队转写、转写中、排队生成纪要及生成纪要中，暂不能移入或彻底删除。
6. 数据库级联删除包含已在回收站的子项。彻底删除课次时显式删除其资料，避免资料的 `SET NULL` 外键使其变为无归属记录。

## 彻底删除与文件失败

彻底删除只允许操作已进入回收站的对象。页面要求用户勾选了解不可恢复，并再次点击确认。

数据库内容删除与 `pending_file_deletions` 记录在同一事务中提交，再执行文件清理。存储失败后内容不会重新出现，待清理记录保留；用户可以在回收站重试。每次最多清理 100 个文件，其他账号的任务不会被处理。文件清理采用幂等删除，重复重试安全。

## 自动清理规则

- 固定保留 30 × 24 小时，按 UTC 删除时间计算，不新增重复的到期字段。
- 独立 Celery Beat 服务每 10 分钟派发清理任务，worker 执行；服务停机期间到期的内容在恢复运行后的下一轮处理。任务繁忙时实际清理可能延后，但到期后恢复接口即拒绝恢复。
- 课程到期会级联删除其全部子内容。之前独立删除的课次和资料按自己的删除时间到期，即使因父级删除而在列表中隐藏，也会自动清理。
- 自动清理与恢复使用相同的课程锁，获取锁后再次检查删除时间，避免误删已恢复或重新删除的对象。单个对象失败不影响其他对象，下一轮重试。
- 自动清理每轮重试待删除文件，每个账号最多处理 100 个文件；剩余或失败任务保留至后续轮次。
- 页面显示剩余天数（向上取整）和准确到期时间，最后三天强调提示，到期禁用恢复。用户仍可提前手动彻底删除。

## 验证

- 后端完整测试 75 项通过：可见性隔离、原始数据保留、父子恢复顺序、账号权限、处理中保护、三十天边界、隐藏子项到期、级联永久删除、文件失败及重试。
- 前端生产构建及本地页面验证。
- 临时本地样本验证课程、课次和资料恢复后的文件内容、文字记录和手动排序一致，验证后清理样本。
