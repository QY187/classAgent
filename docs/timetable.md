# 课程表与课表导入

更新时间：2026-11-25。当前实现已合入 main 并随当日版本上线；此次生产发布只完成启动与健康检查，未新增线上业务验收。实现与既有验证记录见 [fxy 更新记录](fxy-update-2026-11-23.md)，实际版本见 [生产部署](production-deployment.md)。

## 学期与排课

从 `/timetable` 新建学期，填写起始日期、周数及节次时间。起始日及之后六天为第 1 周，此后每 7 天递增；当前日期按北京时间计算，不要求起始日必须是周一。可切换学期，设置首页使用的学期。

排课可填写课程名称、教师、教室、关联课程、星期、小节及起止周，支持单双周。默认学校作息为 5 个大节、13 个小节，可在学期设置中调整：

| 大节 | 小节 | 时间 |
| --- | --- | --- |
| 1 | 1—3 | 08:00—10:25 |
| 2 | 4—5 | 10:40—12:15 |
| 3 | 6—7 | 14:00—15:35 |
| 4 | 8—10 | 15:50—18:15 |
| 5 | 11—13 | 19:00—21:25 |

周次下拉可直达学期内任一周，也可上一周、下一周或回到本周。课程颜色保持一致；同一时段有多门课时叠放展示，点击展开详情并切换前卡。普通排课保存会检查实际周次和节次冲突；全天实践存在专门的重叠展示规则，不意味着任意重复普通课程均可保存。

首页读取选定学期的课表；右侧“今日课程”始终依据实际当前周，不跟随手动浏览的其他周次变化。学期和排课均按当前用户隔离；缩短学期或节次数导致已有排课越界时拒绝保存。

## 从文件导入

1. 先建立或选择学期，在课表页或首页进入“导入课表”。
2. 选择 PDF、CSV 或旧版 `.xls` 文件；不支持将 `.xlsx` 改名为 `.xls`。
3. 查看解析预览，逐项核对课名、教师、教室、星期、小节、周次及单双周，按需编辑和勾选。
4. 确认导入。重复条目自动跳过；发生保存冲突时整批回滚，不留下半批排课。

预览不保存排课。支持已覆盖的网格、课程清单、合并单元格、同格多课程和不连续周次等版式；网页打印 PDF 可结合网格与明细校准。XLS 可识别全周实践，按可识别的工作日生成第 1—10 小节的全天长卡片，保留核对提示，不能承诺所有学校模板都能正确解析。

## 扫描 PDF 与限制

文字页通过 pdfplumber 提取，扫描页使用服务器本地 RapidOCR/ONNX 子进程识别，均不调用外部大模型。此 OCR 入口仅服务于课表解析，普通课件上传不会因此自动启用扫描件问答。

| 限制 | 当前值 |
| --- | --- |
| 单文件 | 最多 8 MiB |
| PDF 页数 | 最多 15 页，其中扫描页最多 5 页 |
| 解析候选 | 最多 300 条 |
| 扫描图像 | 最长边最多 2400px |
| OCR 子进程 | 单次最多 120 秒；同一 API 进程串行执行 |

扫描内容应清晰、方向端正；倾斜、模糊或复杂排版可能误识别。并发繁忙、超时、运行库异常或无可用排课时，页面会提示调整文件或重试。导入前仍须人工校对，不能把识别预览当成已经保存或已经核实的课表。

## 开发与部署

依赖由 `apps/api/requirements.txt` 与 Dockerfile 安装，包括 pdfplumber、xlrd、RapidOCR、ONNX Runtime、OpenCV 及必要系统库。首次升级到含 OCR 的版本需要重建后端镜像；仅重启旧容器不会补齐依赖：

```powershell
docker compose up -d --build api worker beat
```

以上是本地命令；生产按 [部署手册](production-deployment.md) 执行，保留生产 env、数据卷和数据库备份。页面使用本地 Node.js 开发时更新前端依赖并重启；生产还需更新 web 镜像。

相关接口位于 `/timetable`：学期管理、排课管理、周视图，以及 `/semesters/{semester_id}/import/preview` 和 `/import`。均需登录，并由后端核对学期和关联课程归属。
