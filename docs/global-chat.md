# 主对话与跨课程范围

## 后端归属

主对话属于当前用户，`chat_conversations.course_id` 和 `lesson_id` 均为空；课程和课次对话继续使用原有归属。数据库约束只禁止同时绑定课程与课次，启动时幂等调整已有 PostgreSQL 约束，不改写历史记录。

- `POST /chat/conversations`：新建主对话。
- `GET /chat/conversations`：按最近更新时间返回当前用户的主对话。
- 读取消息、发送、改名、搜索、删除和停止生成继续使用原有对话接口。

归属与可见性由后端检查。主对话不会因某门课程被回收或删除而消失，也不能被其他用户访问。它读取到的课堂来源仍需要通过每门课程的归属和回收站检查。

## 当前可用能力

主对话使用 Agent 读取循环，可以查询当前用户课程与课次、读取原文及纪要、按关键词检索课堂内容。课程和课次对话暂沿用原 RAG 回答流程，后续再单独接入 Agent 与工具进度展示。

查询目录时，模型只选择本次工具返回的课程或课次 ID，由后端重新检查真实记录并生成名称、学期或日期列表，不把无原文引用的模型文本作为课堂结论。课堂结论仍需引用本次实际读取的原文。

目前不支持通过聊天生成小测、纪要或删除资料，不能把主对话描述为任意操作入口。主对话使用非流式模型请求，回答完成后通过现有 SSE 发送并保存历史；停止时旧任务不能继续保存回答，但进行中的同步模型请求暂不能立即中断。
