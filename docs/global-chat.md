# 主对话与跨课程范围

## 工作台入口

`/chat` 默认展示主对话入口，点击“新对话”建立独立历史，可以查询当前账号所有可见课程。左侧主对话历史与课程分组分开显示；课程下面直接展示对话，不再展示课次层级，新建对话针对整门课程。

已有课次对话合并展示在所属课程的历史列表中，并保留原课次范围及消息，打开后仍明确提示课次范围，不自动迁移或扩大其检索范围。课程列表接口通过 `include_lessons=true` 读取这些历史，原接口默认行为不变，回收课次的历史仍隐藏。

“添加课程”可以搜索并进入已有课程，也可以输入名称创建新课程。选择已有课程不会复制记录；创建使用原课程接口。课程列表展示当前账号的全部可见课程，不引入额外的收藏或项目绑定关系。进入课程会展开对应分组，页面显示课程范围提示。

侧栏的新建操作使用标题右侧图标：主对话标题旁新建主对话，课程分区标题旁添加课程，每门课程名称旁新建课程对话。按钮保留文字提示和无障碍名称，不额外占据一行；课程折叠时仍可新建对话。

主对话标题、消息、搜索、删除和停止操作复用已有组件，地址使用 `?conversation={id}`，刷新可以恢复已保存历史。

## 后端归属

主对话属于当前用户，`chat_conversations.course_id` 和 `lesson_id` 均为空；课程和课次对话继续使用原有归属。数据库约束只禁止同时绑定课程与课次，启动时幂等调整已有 PostgreSQL 约束，不改写历史记录。

- `POST /chat/conversations`：新建主对话。
- `GET /chat/conversations`：按最近更新时间返回当前用户的主对话。
- 读取消息、发送、改名、搜索、删除和停止生成继续使用原有对话接口。

归属与可见性由后端检查。主对话不会因某门课程被回收或删除而消失，也不能被其他用户访问。它读取到的课堂来源仍需要通过每门课程的归属和回收站检查。

## 当前可用能力

主对话使用 Agent 读取循环，可以查询当前用户课程与课次、读取原文及纪要、按关键词检索课堂内容。整门课程对话也已接入相同读取循环与工具进度，后端限制为当前课程；旧课次对话保留原 RAG 回答流程及本课次范围，见 [课程对话](course-agent.md)。

主对话已支持工具执行步骤实时展示：进行时展开，完成后默认折叠，历史刷新保留；具体边界见 [执行进度](agent-progress.md)。

查询目录时，模型只选择本次工具返回的课程或课次 ID，由后端重新检查真实记录并生成名称、学期或日期列表，不把无原文引用的模型文本作为课堂结论。课堂结论仍需引用本次实际读取的原文。

主对话和整门课程对话已支持明确请求生成课堂小测，课程对话默认当前课程，生成结果展示答题入口，见 [对话小测](agent-quiz.md)。目前不支持生成纪要或删除资料，不能把主对话描述为任意操作入口。Agent 使用非流式模型请求，回答完成后通过现有 SSE 发送并保存历史；停止时旧任务不能继续保存回答，但进行中的同步模型请求暂不能立即中断。
