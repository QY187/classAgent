# 课堂资料导出格式

导航：[文档索引](../README.md) / 纪要与转写 · 编号 001 · 编排日期 2026-11-18

## 导出范围与入口

课次工作台的“导出资料”包含 Markdown、TXT 和“打印 / 导出 PDF”，导出当前课次已保存的智能纪要与文字记录。文字记录页的“下载文字”使用同一套标题、时间、说话人及文件名规则。

## 阅读排版

- PDF：A4尺寸，独立标题与元信息区，蓝灰色标题层级和概览区块，章节、主题、概念及例题保留列表结构。纪要与文字记录分节，正文保留中文换行，文字记录包含编号、起止时间与说话人名称；打印样式提供页脚及页码。较长原文允许跨页，不会为保持整段而留下大块空白。
- Markdown：文档标题、日期与记录信息、纪要二三级标题、完整列表与独立的文字片段。用户文字中的Markdown控制字符转义，防止意外成为标题、HTML或链接。
- TXT：清晰分隔纪要与文字记录；片段间留空行，长于一小时的时间使用时分秒。下载使用UTF-8 BOM与CRLF换行，适配Windows文本编辑器。
- 说话人优先采用用户命名；文件名处理Windows不允许的字符。

## 已编辑纪要与安全

已手动编辑的纪要按保存的富文本内容导出，保留标题、列表、加粗和待办状态。PDF使用受限HTML标签及属性，移除脚本、图片、事件和危险链接，打印文档不加载外部资源；Markdown与TXT转换为对应文本结构。原文与标题在HTML中按文字转义。

打印窗口等待字体就绪及完成布局后唤起打印，不使用固定300毫秒延时。PDF仍通过浏览器打印窗口选择“另存为PDF”；浏览器版本和打印设置可能影响最终分页。页脚页码已在本地Edge验证，建议关闭浏览器附加的默认页眉页脚。
