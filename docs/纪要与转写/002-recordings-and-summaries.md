# 录音、文字记录与智能纪要

本文说明当前课次资料流程。课程与课次按本人归属管理；具体线上版本及验证范围见 [生产部署](../开发与部署/003-production-deployment.md)，本地启动见 [开发说明](../开发与部署/001-local-development.md)。

## 从课次采集音频

创建课程与课次后进入 `/lessons/{lessonId}`。可以直接上传音频，也可以允许麦克风权限后在浏览器录音，结束时上传。浏览器通过 MediaRecorder 保存音频，同时尝试浏览器语音识别；实时识别能力取决于浏览器、权限和网络，不支持时仍可保存音频。

有已确认的浏览器文字时随录音保存；直接上传音频，或录音没有已确认文字时，由 Worker 使用百炼文件转写，需要有效服务端配置。音频保存成功和转写完成分别处理，不能将上传成功提示理解为纪要已经生成。转写结果包含片段与时间，标签可能需要人工校订，不保证可靠获知真实说话人姓名。

## 校对文字并回听

在 `/lessons/{lessonId}/transcript` 查看文字片段、起止时间与说话人，可以修改文字、合并片段、管理说话人显示名，并定位音频回听。通过书签收藏片段或标记“没听懂”，再从列表返回原文与录音位置。

合并片段会维护相关书签；替换录音及文字记录后会清理旧片段书签。课堂原话、人工修订和模型生成的纪要属于不同资料层，阅读时应核对实际保存内容及来源。

## 生成、编辑与更新纪要

进入 `/lessons/{lessonId}/summary`，根据已保存文字生成智能纪要，查看课堂主题、概念、例题等整理内容，并通过可用来源回到原文。默认纪要模型使用服务端 DeepSeek 配置；生成是模型调用，不等于课堂事实已经验证。

纪要支持富文本编辑、保存及重新生成。已手动编辑内容以保存版本展示和导出，页面会提示主动重新生成将覆盖这些修改。文字记录更新后应核对纪要是否过期，按需重新整理，不能假定旧纪要已同步为最新课堂内容。

## 状态和失败处理

课次工作台和待处理列表分别显示音频转写与纪要状态，可查看排队、处理中、完成、失败或需要更新等情况。出错时按当前阶段、配置和失败原因处理；在未核实完成前，不应根据界面等待结束推断后台任务成功。

API 负责业务请求与任务投递，Worker 执行实际转写或纪要生成，Beat 处理定时补偿和清理；正常上传不需要先等待 Beat。查看本地日志及重启方式见 [开发说明](../开发与部署/001-local-development.md)。

## 导出与继续学习

课次资料导出支持 Markdown、TXT 与浏览器打印 PDF，格式及已编辑内容处理见 [课次导出](001-lesson-export.md)。整门课程的四类 PDF ZIP 和下载前真实预览是另一入口，见 [课程导出](../课程/003-course-export.md)。

可从纪要生成有课堂来源的知识点卡片，或对选定课堂记录/已解析课件生成小测。问答和出题仍需要检查来源、范围及内容是否足够，详见 [课程 Agent](../问答与Agent/006-course-agent.md) 和 [小测设置](../复习与小测/001-quiz-generation-settings.md)。
