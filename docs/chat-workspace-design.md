# 课程与课次问答工作台

## 使用方式

### 主对话

工作台默认支持不绑定课程与课次的主对话，跨当前账号全部可见课程使用 Agent 读取工具。左侧独立展示主对话历史，下方按课程直接展示对话，不再展示课次层级。新建对话针对整门课程，已有课次对话保留原范围并合并在课程历史中。“添加课程”支持搜索进入已有课程或创建新课程。具体能力及验证见 [主对话与跨课程范围](global-chat.md)。以下逐步显示说明针对原课程与课次回答流程，主对话当前在模型完成后发送校验后的完整结果。

### 回答逐步显示

- 工作台通过 `POST /chat/conversations/{conversation_id}/ask/stream` 接收 SSE，模型真实流式生成；每条结论完整且通过来源编号校验后发布累计回答快照，不直接展示原始 JSON 或尚未校验的零散文字。
- 传输事件为 `status`、`answer`、`done`、`error`，空闲期间发送心跳。完成事件携带已入库的完整历史，时间字段按普通 API 格式编码；反向代理收到 `X-Accel-Buffering: no` 关闭本次响应缓冲。
- 临时回答仅在当前页面展示。失败时清除预览并读取已保存状态，问题保留用于重试；连接离开后后台继续完成原请求，刷新或切回对话可读取处理状态及最终答案。
- 流式与普通提问共用生成占用、请求幂等、权限校验、课堂检索及最终保存逻辑，不新增数据表。重新回答不包含在本次功能中。

### 停止生成

- 问题保存并开始生成后，输入区显示“停止生成”；刷新或切回正在生成的对话也可以停止。停止请求使用原问题的请求编号，重复停止不会影响后来发起的新问题。
- 后端锁定对话后标记问题为 `cancelled`，保存已有的来源校验快照及引用为同状态的助手消息，并释放生成占用。尚无已校验内容时仅保留问题。
- 模型流接收下一片段时检查占用，发现已停止即退出并关闭上游连接；即使上游暂时没有数据，停止后的任务也不能发布新内容或写入最终答案。页面可立即继续提问。
- 部分回答标明“已停止生成 · 回答未完成”，刷新后仍可查看，引用仍可定位原文；已取消的问题及部分回答不作为后续已完成上下文。
- `generation_preview_json` 是对话上的临时快照字段，独立保存模块只写入已校验结论；停止、完成和失败时清空。已有数据库增加该字段并扩展消息状态约束，迁移可重复执行。


独立入口为 `/chat`，左侧课程分组支持展开和收起。课程下可新建检索整门课程的对话；已有课次对话直接显示在课程历史中，仍保留原课次范围。右侧展示历史并继续提问，标题与输入区明确显示当前范围。对话编号记录在地址参数中，刷新后重新读取数据库中的历史。课程页的“课程问答”链接通过 `/chat?course={course_id}` 进入工作台，展开并高亮对应课程；原问答页面地址自动跳转，旧问答组件和旧后端提问接口已删除。

- 课程对话综合所属课程全部可见课次的转写与纪要，课次对话只检索所属课次；均不自动借用其他课程或上传课件。
- 每个问题和回答均保存，引用保存为快照，默认折叠；引用可定位到原文时间点。
- 追问读取本对话最近八条已完成消息，仅用于理解语境，每次仍按该对话的课程或课次范围重新检索。历史回答不能替代课堂依据。
- 第一条问题作为初始标题，用户可单独改名。支持按课程、课次和对话标题搜索，最多显示最近一百条。
- 回答中可以切换到其他对话；返回后读取当前处理状态。回答失败保留问题，允许重试最后一条未完成问题。
- 手动删除对话会永久删除其消息，页面必须确认；不删除课程、课次或课堂资料。课次进回收站时，对话一起隐藏，恢复后可见；课次到期或手动彻底删除时，对话与消息级联清理。

## 数据表

| 表 | 内容 |
| --- | --- |
| `chat_conversations` | 对话 ID、可空课次 ID、可空课程 ID、用户 ID、标题、创建与更新时间、生成占用令牌和时间；课程与课次不能同时指定，均为空表示主对话 |
| `chat_messages` | 消息 ID、对话 ID、请求 ID、顺序、角色、文本、状态、引用 JSON 快照、错误提示、创建时间 |

新表由现有启动流程 `Base.metadata.create_all` 建立。已有对话表由独立迁移补齐课程 ID、放开课次 ID 非空限制，并增加互斥归属约束，已有课次对话和消息不变。无需修改原有课程、课次表字段。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| `chat/access.py` | 课次、对话归属校验及课程到对话的加锁顺序 |
| `chat/conversations.py` | 对话新建、列表、标题修改 |
| `chat/messages.py` | 历史消息及引用读取 |
| `chat/sending.py` | 保存问题、请求幂等、调用问答、保存回答、失败处理 |
| `chat/generation.py` | 五分钟生成占用期限判断 |
| `chat/context.py` | 最近已完成上下文读取 |
| `chat/tree.py`、`chat/search.py` | 课次树与对话搜索 |
| `chat/deletion.py` | 单个对话永久删除 |
| `rag/service.py` | 课程或课次范围检索、答案生成与引用校验 |
| `ChatLessonTree`、`ChatConversationList` | 课次筛选、展开、对话列表与新建 |
| `ChatThread`、`ChatMessageList`、`ChatComposer` | 历史读取与发送协调、消息及引用展示、输入交互 |
| `ChatTitleEditor`、`ChatDeleteButton` | 独立改名与删除确认 |

## 发送与异常处理

1. 检查用户归属，先锁所属课程再锁对话。
2. 用请求 ID 检查重复请求。同一请求已经完成则读取已有结果，同一编号不能用于不同问题。
3. 保存问题及生成占用后提交事务，再调用检索和模型，避免长期持有行锁。
4. 保存回答前重新检查课次可见性、对话归属和占用令牌；回收或删除后的对话不写入答案。
5. 失败记录可重试状态并释放占用。进程意外退出时占用最多保留五分钟，再读取历史会显示可重试。
6. 回答保存与用户消息完成状态在同一事务内提交。消息顺序和请求角色组合由数据库唯一约束保护。

课程与课次回答通过 SSE 展示已校验的累计结论；主对话当前采用完整结果返回。关闭页面不等于取消后端问答；重新打开可以读取已经保存的消息。

- 本地页面实际验证新建、带依据回答、连续追问、修改标题、刷新恢复和标题搜索。
- 后端完整测试 94 项通过，前端生产构建和类型检查通过。验证课程收起后课次隐藏、课程对话界面范围提示，以及存量数据库迁移重复执行安全。此前临时验证对话及四条消息已清理。功能未推送、未部署线上。
