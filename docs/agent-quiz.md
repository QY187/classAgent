# 通过主对话与课程对话生成课堂小测

## 范围与执行

出题与课程管理意图通过一次模型调用统一识别，判断普通小测、薄弱点练习及课程管理委托，不要求用户使用固定开头。例如“去给我将测试课程的第二讲创建5道小测”识别为普通小测，不会被另一个管理分类器当作不支持的操作拦截。分类输入包含当前请求、绑定课程与最近对话，仅在实际请求的澄清场景承接授权；咨询、取消、否定、解答已有题与引用命令应判为无委托。分类失败返回错误，不默认为授权。分类最多等待 15 秒；分类后重新检查请求是否已取消，再进入受控执行循环。课程权限、范围、题型题数和幂等保存仍由原后端工具校验。

主对话、整门课程对话和课次对话均已接入。用户明确要求生成题目时才向模型提供 `generate_quiz`；普通查询、否定指令或询问如何生成不会开启操作工具。上一条明确生成请求遇到范围澄清时，简短补充课程、课次或题型可继续该请求。课程对话默认当前课程，未限定课次时使用整门课程；指定课次时先定位，有歧义再澄清。课次对话只为当前课次出题，后端在调用及保存前校验范围。

工具只接受当前用户可见课程。主对话的课程必须在本次查询工具结果中出现；课程对话由后端验证并绑定当前课程，可直接作为已确认范围，无需重复查询课程目录。指定课次仍必须在本次查询结果中出现。范围不明确时模型应先澄清。题数为 3–15，题型为单选、判断或混合，与现有页面一致。生成复用原小测服务及来源摘录验证，生成成功立即由后端返回结果，不让模型补写题目或答案。

每条问题最多对应一组小测，`quizzes.agent_request_key` 保存问题消息 ID 并有唯一约束。已生成结果会在重试时复用；原课程页生成接口不使用这个字段。已回收范围不能通过重试重新生成。长时间生成不持有对话锁；写入前重新锁对话检查生成令牌与课程绑定，再校验课次归属、范围与原文，停止、回收或来源移到其他课程后不保存结果。生成已经完成再停止时，小测保留在课程历史中。

历史接口按问题关联实际可见小测，返回 `artifacts`，仅包括小测编号、名称、课程、题数和范围，不包含答案、解析、题干或选项。对话删除不删除已经创建的小测；课程或课次回收后相应卡片隐藏。详情和答题入口继续使用原接口权限。

## 验证

新增测试覆盖请求识别、参数约束、默认禁用写工具、实际服务生成、历史结果、答案隔离、重复复用、范围发现、其他用户拒绝、回收隐藏、停止前禁止保存以及澄清请求。

## 前端

小测结果展示在对应问题的执行步骤下方，包含名称、课程、实际题数与范围。点击“开始答题”进入现有 `/quizzes/{id}` 页面，提交后才查看成绩、答案及解析。刷新后从历史接口重新读取真实卡片；原小测回收或范围不可见时不保留可点击的过期卡片。聊天生成可能需要较长时间，前端连接超时调整为四分钟，不改变后端读取循环预算和原出题请求超时。

53 项相关后端测试、前端类型检查和生产构建通过。本地真实模型根据“当前版本ASR验收”的第二讲生成三道单选题，步骤与卡片刷新后保留，“开始答题”成功进入原答题页，作答前未展示答案与解析。本轮生成的对话和小测保留供用户试用。

课程对话接入后，76 项相关后端测试通过，前端类型检查与生产构建通过。真实课程对话生成三道判断题，默认使用当前课程，连续的新问题生成独立小测，整门课程范围和答题入口经页面验证。新请求必须实际执行生成工具，历史成功消息不能作为本次完成结果；当前课程由后端确认，不需要为了满足范围校验重复查询课程目录。
