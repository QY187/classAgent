# Agent 自然语言入口补齐

## 重试转写

统一意图解析支持 `retry`，例如“第二讲没转出来，帮我再跑一次”。主对话需明确课程与唯一课次；课程对话默认绑定课程；课次对话可以使用当前课次。咨询、取消、历史命令不授权重试。

实际执行仍核对原始消息、唯一目标、范围、当前任务失败状态、已有文字与录音，以及幂等回执。只登记转写重试，不把登记等同于完成，不重试纪要。

## 操作后的查询

统一解析输出 `queries` 和 `catalog`，记录用户要求的最终查询类别及目录类型。执行循环接收解析参数，并在实际操作完成后检查查询是否已读取；缺失时要求补齐，仍缺失则明确列出未完成内容。

“创建课程后，把我目前开的课都展示一下”不需要匹配“查询、列出”等关键词。生成小测后也会继续完成同条消息的查询要求，已有成功动作不重复执行。查询结果仍由既有证据存储重新核验。

## 核对操作结果

“现在是不是已经改过来了”等表述解析为只读的 `verify`。后端读取当前对话的实际成功回执，并重新读取课程、课次、知识点或转写重试任务，区分历史执行成功、当前仍一致、后来发生变化、目标不可见和无成功回执。

回答明确说明核对的是最近有回执的相关操作，不把其他无回执请求说成成功。不从历史助手回复判断成功，不因此恢复写入权限；本次还要求查询或新操作时单独执行，并保留核对结果。

## 课次对话

课次对话接入与主对话、课程对话一致的 Agent 工具循环、步骤显示、取消检查、回执和历史保存，不再单独走旧检索问答入口。

- 课程和课次范围来自后端对话记录；解析提供当前名称用于理解“这门课、这节课”。
- 原文、纪要、知识点、错题、处理状态、成绩和小测读取受当前课次约束。
- 修改课次、知识点状态、转写重试和出题均限当前课次；普通小测未传范围时由后端固定当前课次。
- 薄弱点练习保存前重新校验所选记录来源仍属于当前课次。
- 可修改当前所属课程信息、明确添加同课程的新课次；新建课程仍须在主对话执行。整门课程进度请在课程对话查询。
- 不支持的操作、同名目标、不完整日期、未知目标仍须澄清。

## 当前验收状态

本次为本地实现，Python 语法解析及差异格式检查通过；尚未运行自动化测试或真实模型业务验收，尚未部署。本说明不承诺模型对所有自然表达均能正确识别。
