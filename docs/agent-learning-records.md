# Agent 查询学习记录

## 知识点状态

- 工具 `list_knowledge_points` 复用知识点服务，支持课程、课次、关键词、状态和分页。
- 主对话默认查询所有可见课程；课程对话默认只查询当前课程。其他用户和回收站资料不参与查询。
- `new`、`review`、`mastered` 分别表示未学习、需要复习、已掌握，均为用户手动标记，不代表 AI 评估的能力，也没有到期时间。
- 数量统计覆盖当前筛选的全部记录，列表可分页。该工具只读取，不改变学习状态。
- 学习记录使用本次真实查询编号。最终回答由后端重新查询并呈现，拒绝模型虚构或引用历史查询编号；空结果也能明确展示。
- 知识点内容和学习状态不是课堂事实引用；解释课堂知识时仍需读取文字记录核对来源。

验证：`test_agent_knowledge` 覆盖筛选计数、分页、权限、回收站、真实状态、空结果、生成期间状态变化，以及对话步骤和刷新恢复。

## 错题本

- `list_wrong_questions` 复用错题本服务，默认全部状态，可筛选待巩固或已掌握、课程、来源课次及题干关键词。
- 答对后保留错题历史，状态使用最近的小测作答或错题重练结果，与错题本页面一致。
- 小测答错次数与重练次数分开展示，避免将所有重练都算成答错。
- 只读取已作答的错题元数据，不提供正确答案或解析，不新增作答、不修改记录。
- 同样使用本次查询编号和后端重新查询输出，支持没有错题的情况。

验证：`test_agent_wrong_questions` 覆盖重复答错归并、答对后的状态、权限和范围、删除可见性、空结果及对话持久化。
