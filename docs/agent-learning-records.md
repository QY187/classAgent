# Agent 查询学习记录

## 知识点状态

- 工具 `list_knowledge_points` 复用知识点服务，支持课程、课次、关键词、状态和分页。
- 主对话默认查询所有可见课程；课程对话默认只查询当前课程。其他用户和回收站资料不参与查询。
- `new`、`review`、`mastered` 分别表示未学习、需要复习、已掌握，均为用户手动标记，不代表 AI 评估的能力，也没有到期时间。
- 数量统计覆盖当前筛选的全部记录，列表可分页。该工具只读取，不改变学习状态。
- 学习记录使用本次真实查询编号。最终回答由后端重新查询并呈现，拒绝模型虚构或引用历史查询编号；空结果也能明确展示。
- 知识点内容和学习状态不是课堂事实引用；解释课堂知识时仍需读取文字记录核对来源。

验证：`test_agent_knowledge` 覆盖筛选计数、分页、权限、回收站、真实状态、空结果、生成期间状态变化，以及对话步骤和刷新恢复。

## 错题本

- `list_wrong_questions` 复用错题本服务，默认全部状态，可筛选待巩固或已掌握、课程、来源课次及题干关键词。
- 答对后保留错题历史，状态使用最近的小测作答或错题重练结果，与错题本页面一致。
- 小测答错次数与重练次数分开展示，避免将所有重练都算成答错。
- 只读取已作答的错题元数据，不提供正确答案或解析，不新增作答、不修改记录。
- 同样使用本次查询编号和后端重新查询输出，支持没有错题的情况。

验证：`test_agent_wrong_questions` 覆盖重复答错归并、答对后的状态、权限和范围、删除可见性、空结果及对话持久化。

## 小测成绩与答题记录

- `list_quiz_attempts` 读取当前用户已提交的小测成绩，按作答时间倒序，可按课程、小测和标题关键词筛选及分页。主对话默认全部课程，课程对话默认当前课程。
- 已生成但没有提交的小测不计入成绩；同一小测多次提交分别计为作答记录。列表只含题数、答对数与正确率，不含答案或解析。
- 总记录数覆盖筛选后的全部作答，`page_summary` 仅汇总实际显示的这一页；正确率按总答对题数除以总答题数计算，不将不同题数的小测百分比直接平均。没有作答时正确率为空，不显示成 0%。时间按北京时间呈现。
- `get_quiz_attempt` 按真实作答编号读取题目、选项、实际选择、对错、保存的答案与解析，默认每页 5 题，最多 15 题。它读取已提交记录，不能使用未提交的小测编号获取答案。
- 历史解析来自出题时保存的内容，不代表经过独立语义正确性验证。课堂引用仅在来源课次仍可见、属于当前课程且摘录仍出现在对应原文时显示；摘录已变化或来源不可用时明确提示并移除引用。课程整体小测的历史成绩可保留，但不能引用已经回收的课次。
- 课次范围只查询该课次的小测，不将跨课次小测的成绩及题目混入；其他用户、其他课程对话范围和回收站记录均受权限约束。
- 成绩使用本次 `quiz_result_query_id` 返回，最终回答由后端重新读取并复核，模型不能编造成绩或引用旧查询编号。可与知识点、错题查询一起展示。查询不生成小测、不提交答案、不自动修改掌握状态。
- 对话中展示“查询小测成绩”“读取答题记录”的步骤，刷新后保留结果与可点击的课堂来源。

示例：“我最近 5 次小测成绩怎么样？”“展开最近一次小测，看看我选了什么、哪些题答错了。”“查询这门课的小测成绩和待巩固错题。”

验证：`test_agent_quiz_results` 覆盖未提交答案保护、严格参数、重复作答与分页加权统计、权限和范围、回收可见性、来源变化、查询编号真实性、回答前复核，以及主对话和课程对话持久化。

本地验收：96 项相关测试通过。真实模型在主对话中调用成绩工具，未作答时显示空记录；刷新后回答和工具执行步骤仍保留。已提交成绩、逐题作答和课堂引用通过数据库及对话服务测试验证。

## 根据薄弱点出题

- 用户明确要求后提供独立动作 `generate_practice_quiz`。普通出题请求继续使用 `generate_quiz`；查询、否定请求和能力询问不会开放写工具。
- 示例：“根据需要复习的知识点生成 3 道判断题”“根据错题生成 5 道选择题”“根据这门课的薄弱点出题”。
- 先读取本次需要复习的知识点、待巩固错题，只选择当前已查询且属于一门课程的记录，排除未学习及已掌握内容。
- 每次最多选择 20 个知识点和 20 道错题。来源课次由这些记录确定，不能混入其他课程。
- 使用学习记录确定主题，正确答案仍依据当前课堂文字记录。只向出题服务提供对应的原文片段，保留引用附近文字；单个有效来源也可尝试生成至少 3 道不同题目，资料不足则失败。
- 复用小测生成、答题和错题收集服务，生成独立的新小测，不重复保存旧错题或更改知识点状态。
- 没有适用记录时展示查询结果；来源缺失、原文变化或学习状态变化时明确提示，不能悄悄生成普通小测。
- 保存前再次核对身份、范围、学习记录状态和来源；停止生成不保存，按问题编号保持幂等。对话只显示题数与答题入口，正确答案和解析在提交答案后展示。

验证：`test_agent_practice` 覆盖动作授权、澄清继承、普通出题隔离、限定原文、新题结果与幂等、错题记录不变、未查询目标、状态及来源异常、越界、取消和生成期间变化。

本地验收：86 项相关测试、前端类型检查与生产构建通过。真实模型在课程对话中完成知识点及错题查询，并按一个知识点的课堂来源生成 3 道判断题；答题页不提前显示答案，重新进入对话后保留工具步骤和答题入口。验证使用的临时知识点状态已恢复。
