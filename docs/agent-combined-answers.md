# Agent 多项读取结果组合

## 范围

同一问题可以同时返回课程/课次目录、课程进度、小测成绩与已提交题目详情、知识点/错题记录以及带原文引用的课堂结论。模型在一个最终 JSON 中选择各类本次真实查询编号，`answers.py` 逐类调用原有结果存储核验，再组合为一条回复。

各业务存储继续负责身份、范围、资料版本和最新统计，组合层不查询数据库、不复制业务计算。模型附加的答案和分数不会进入展示。伪造查询编号仍触发协议修复，不能当成某一项暂不可用而跳过校验。

某一类真实查询结果因资料回收或业务不可用而无法核对时，其他已核验结果保留，并显示该项当前不可用的提示。不回传内部异常；全部请求结果都不可用时返回 `operation_failed`，不展示缓存的事实或统计。未登录等身份错误继续向上传播。

## 引用

小测题目详情和课堂结论的引用按组合顺序连续编号。在各自的渲染器中传入 `citation_offset`，避免事后替换正文里的数字，保持原文中的编号不受影响。引用的课次、时间点、片段编号及权限校验保持原有规则。

## 验证

新增 7 项测试覆盖所有读取类型组合、成绩与课堂引用编号、单项不可用、伪造查询编号拒绝、状态变化后重新核验、课程回收后的缓存拒绝，以及聊天保存完整结果。既有成绩回归进一步断言课程回收后只显示不可用提示。

真实模型使用隔离数据验证了主对话和课程对话同时查询“缺少纪要的课次 + 最近一次成绩”，均同时返回第二讲缺少纪要与 3/5、60% 的真实记录。课堂结论与知识点状态的组合也同时返回，结论保留本次原文引用。

本项处理读取结果组合。成功写动作和小测生成仍沿用原有真实回执与结束规则，读写混合任务的完整呈现另行完善；也不改变写意图授权、澄清接续和原文读取分页。
