# 课程库首页统计

首页通过 `GET /courses/overview` 获取当前登录用户的统计，不新增数据库表。

## 待处理课次

可见课次满足任一条件即计数一次：

- 转写尚未完成（包括未上传、排队、处理中和失败）。
- 没有状态为 completed 或 edited 且内容非空的可用纪要。

已有旧纪要但正在重新转写的课次仍计入。课程或课次进入回收站后不再统计。

点击首页待处理数量或提示可进入 `/pending-lessons` 明细页面。`GET /courses/pending-lessons` 与首页共用筛选条件，支持 offset / limit 分页（每页默认 20，最多 50）。明细显示课程、课次、日期、处理阶段、失败原因和进入课次的链接。转写失败只读取最新任务的原因；已重试或转写完成时不展示旧失败原因。纪要失败读取当前纪要错误，没有记录原因时明确说明。页面支持手动刷新，待处理项清空时显示完成状态。

## 最近学习

从以下真实记录中取最新时间，显示日期与标题，并链接到对应页面：

- 当前用户已提交的小测作答。
- 当前用户课程中知识点的最近复习标记。
- 当前用户未归档对话中已完成的提问。

失败、取消、处理中消息与自动转写、生成纪要不计入。尚无记录时显示空状态；这是活动日期，不代表学习时长或实际掌握程度。

接口使用 UTC 时间，页面按浏览器时区显示。统计加载失败时显示重试入口，避免以 0 冒充加载结果。

验证覆盖：缺少纪要、空白纪要、转写中、失败、账户隔离、回收站过滤、最新活动选择、失败消息排除、归档记录过滤与正确跳转地址。
