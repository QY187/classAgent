# Agent 资料处理与小测工具

## 待处理课次查询

`list_pending_lessons` 复用首页明细服务，返回真实处理阶段、失败原因、课次入口及分页信息。主对话省略课程查询本人所有课程；课程对话限定当前课程。已回收和他人的资料不返回。

最终响应使用 `workflow.query_ids` 引用本次查询编号，后端重新查询后呈现，防止模型编造数量或沿用旧错误。

验证覆盖跨课程、范围限制、分页、错误原因、非法参数、模型循环及最终回答重新核对。

## 未作答小测查询

`list_unanswered_quizzes` 查询 ready 状态且本人没有提交记录的小测，草稿及他人的资料不计入。返回题量、标题和答题入口，不读取问题答案。支持课程、来源课次、标题搜索和分页。未提交不等于从未打开或没有开始作答；一次提交后即从列表排除。

最终回答复用 workflow 查询编号，提交状态变化后重新核对。

## 课次处理详情

`get_processing_detail` 读取唯一课次的当前阶段、最近转写任务及进度、纪要状态。没有任务时明确返回空；旧任务失败不覆盖当前生成纪要状态。转写进度不代表纪要进度，不返回音频对象路径。

## 重试失败转写

`retry_transcription` 只按当前用户明确指令登记重试。先定位本条指定的唯一课程和课次，查询当前任务；同名或缺少标题需补充明确指令，不从历史授权。仅当前转写失败、录音可用且没有已有文字时允许，已有文字不会清除。排队、处理中、完成课次不重复提交。

任务和 AgentAction 回执同一事务保存；提交后投递队列。队列暂不可用时 beat 每分钟补投递，每次最多 50 个待执行任务。worker 用任务锁及 queued 阶段抢占，重复投递不重复转写。执行回执只说明登记与等待处理，不声称转写完成。

验证覆盖否定和咨询不授权、相同消息幂等、队列失败恢复、worker 重复投递、他人资料拒绝、已有原文保留及无音频拒绝。

## 修改课程、课次信息

`update_course` 修改名称或学期，`update_lesson` 修改标题或日期。当前指令的确定参数由后端核对，未指定字段保持原值；不删除原文或学习记录。先查询唯一目标，同名、错误课程和模型额外添加的字段拒绝执行。沿用消息动作回执保证同一消息幂等。

支持示例：课程对话“把第三讲改名为二叉树，日期改为2026-10-05”；主对话“把数据结构课程的第三讲改名为二叉树”；“把数据结构课程改名为算法基础”；“把数据结构课程的学期改为2026秋”。日期必须完整 YYYY-MM-DD，只有10月5日需补充年份并重新发出明确指令。暂不支持根据历史补全写入目标或多目标批量修改。
