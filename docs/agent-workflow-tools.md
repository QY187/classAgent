# Agent 资料处理与小测工具

## 待处理课次查询

`list_pending_lessons` 复用首页明细服务，返回真实处理阶段、失败原因、课次入口及分页信息。主对话省略课程查询本人所有课程；课程对话限定当前课程。已回收和他人的资料不返回。

最终响应使用 `workflow.query_ids` 引用本次查询编号，后端重新查询后呈现，防止模型编造数量或沿用旧错误。

验证覆盖跨课程、范围限制、分页、错误原因、非法参数、模型循环及最终回答重新核对。

## 未作答小测查询

`list_unanswered_quizzes` 查询 ready 状态且本人没有提交记录的小测，草稿及他人的资料不计入。返回题量、标题和答题入口，不读取问题答案。支持课程、来源课次、标题搜索和分页。未提交不等于从未打开或没有开始作答；一次提交后即从列表排除。

最终回答复用 workflow 查询编号，提交状态变化后重新核对。

## 课次处理详情

`get_processing_detail` 读取唯一课次的当前阶段、最近转写任务及进度、纪要状态。没有任务时明确返回空；旧任务失败不覆盖当前生成纪要状态。转写进度不代表纪要进度，不返回音频对象路径。
