# Agent 课程管理

## 创建与修改的自然语言理解

- 主对话和课程对话通过模型统一提取创建课程、添加课次、修改课程/课次名称和日期、修改知识点状态的委托与参数，不再要求用户匹配固定正则句式。例如“给数据结构安排一节课，标题叫树的遍历”“数据结构这门课换个名字，叫算法基础”。
- 同一条消息只解析一次上述写入意图；目前与出题意图解析分别调用模型，因此普通读取问题也会增加写入分类调用，超时上限为 15 秒。解析失败终止本次请求，不回退到猜测执行。
- 分类输出接受严格限定的动作和字段，不接受模型提供的数据库 ID。咨询、引用、取消、冲突或批量修改不直接产生写权限；缺少参数时先澄清。历史只可承接正在澄清的实际委托。
- 当前绑定课程提供“这门课”的范围；主对话的课次操作仍要求明确课程。模型提取的名称、状态和修改字段固定绑定本条原始消息，执行模型不能替换参数或扩大修改范围。
- 业务层继续校验归属、唯一目标、重复名称、完整日期、生成令牌、幂等回执和事务。完整年月日可规范化为 YYYY-MM-DD；不完整日期不猜年份。创建课程后添加课次仍须先取得本条创建动作的真实回执。
- 新实现尚未运行自动化测试或真实模型验收，尚未部署。

## 课程进度查询

- 工具 `get_course_progress` 复用课程页面的业务统计，返回课次、文字记录、可用纪要和手动标记的知识点数量。
- 缺少纪要的课次单独分页，区分尚无纪要、排队、生成、失败、过期和空内容。回收站中的课程、课次不参与查询。
- 课程对话默认当前课程；主对话先定位课程。不能跨用户或越过绑定的课程范围。
- 最终回答必须引用本次实际查询的 `progress_query_id`，服务端重新读取统计和明细，模型不能提供自拟数量。
- 知识点数量表示用户的手动状态，不解释为考试能力或学习完成率。

验证：课程统计、分页、纪要状态、权限、回收可见性、查询后数据变化及伪造查询编号测试。

## 写入执行基础

- `agent_actions` 保存每条聊天问题的已执行动作、参数和实际回执；每条问题每种动作最多一次。
- 对话锁、生成令牌和问题状态在写入前复核，取消后的请求不能继续写入。
- 业务变更与回执在同一事务提交；失败一起回滚，重试相同参数直接返回已有回执，修改参数要求新问题。
- 写工具只能从后端绑定的动作回调执行，模型无法通过参数自授权。成功回答从实际回执生成。
- 此基础不单独开放业务写权限；具体课程、课次、知识点接入各自验证。

验证：实体与回执原子性、失败回滚、取消前检查、相同请求重放和修改参数冲突。

## 创建课程

- 主对话支持“帮我创建数据结构课程”；名称必须是指令中明确指定的名称。暂不自动填入学期。
- 普通能力询问、否定命令、课堂引文不会开放写工具；缺少名称先澄清，可直接补充名称。课程对话提示进入主对话。
- 已有同名课程时提示选择已有课程或使用其他名称，不猜新名称。
- 复用页面的创建服务，增加默认保持原行为的事务参数；实体与回执原子保存。
- 聊天显示真实创建回执及课程链接；刷新保留，后续回收课程时隐藏链接。失败或停止前已经成功保存的动作仍显示回执，重试不重复创建。

验证：明确授权、精确名称、缺少名称、同名拒绝、对话范围、失败重试、重复调用、取消与回收可见性。

## 添加课次

- 课程对话支持“添加第三讲”，主对话支持“在数据结构课程下添加第三讲”。标题不明确时先询问。
- 一条指令可依次创建课程、添加课次；后一步使用前一步的真实课程 ID，创建课程失败时不能擅自向已有课程添加。
- 主对话必须先查到明确命名的唯一课程；课程对话严格绑定当前课程。同名课次不重复创建。
- 日期可用“日期为 2026-10-03”明确指定，未指定保持为空，非法或不完整日期不猜测。
- 与页面共用创建课次服务及排序规则，新课次排在现有课次之前。动作与回执同事务提交，并显示课次链接。

验证：组合创建、既有课程定位、对话范围、标题与日期校验、同名拒绝、依赖失败和默认排序。

## 修改知识点状态

- 支持“把前序遍历标记为已掌握”，也支持明确标记为“未学习”“需要复习”。每条问题最多修改一个知识点。
- 必须先查询当前范围中的知识点，模型不能直接使用历史或自拟 ID 修改。后端再次匹配用户指定的名称、课程、课次及状态。
- 同名多条先澄清，可明确说“把数据结构课程第三讲的前序遍历标记为已掌握”；不自动批量修改或从成绩推断掌握状态。
- 共用知识点页面的状态更新服务；内容和标题保持不变。状态已相同时不刷新复习时间；修改与回执原子保存，重试不会重复写入。
- 回执显示已执行的状态变更和知识点入口，回收或删除后的入口隐藏。

验证：明确指令与否定、先查后改、名称和状态校验、同名歧义、范围隔离、取消、回收可见性、相同状态及重放。
