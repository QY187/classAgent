# 会话上下文压缩与历史召回

默认会话记忆预算16000估算Token，扣除当前问题及协议预留后，达到80%时在规划和工具调用前同步压缩。合并旧检查点和新增前缀，通常保留最新两轮完整问答；通过through_position/version记录覆盖和并发版本，原聊天不删除、已覆盖前缀不重复作为近期原文。后台摘要仅预热，失败且仍超预算时明确暂停本轮，保留记录供重试。每批完整轮次约12000预算单位，最多3批、45秒预算；停止生成后不写结果。

摘录须逐条核对原消息，凭据标签和记忆命令不进入摘要及召回，不作为事实或操作授权。历史先按用户及课程课次过滤，关键词与可选1536维pgvector召回结合；向量故障降级关键词，回收站与来源删除沿用可见性约束。索引保存原文哈希并重核对，未配置向量服务时不宣称语义召回。MEMORY_CONTEXT_BUDGET、MEMORY_SUMMARY_ENABLED、MEMORY_SEMANTIC_ENABLED控制服务，摘要、同步压缩及向量分别按用户额度计量。

模型无关预算采用中文每字2、其他连续文本每3字节1的近似，非供应商精确分词或整个模型窗口。历史旧数据没有批量向量回填，压缩不保证保留所有逐字细节；课堂事实仍重新查证。本阶段提供完整上下文服务，用户长期偏好、管理页与临时模式在下一笔独立提交接入。

依据：LangChain SummarizationMiddleware及Claude Context editing官方文档。既有真实默认模型16轮合成样例在6000预算下10762降至2306，保留Python约束和最新两轮，1次模型调用，样例数据已清理。本次提交整理还在隔离目录重新验证，不改运行目录。
