# 手机端布局

本轮以 390px 竖屏作为主要排版宽度，兼顾 360、375、414、430px；这些是测试视口宽度，不表示具体手机型号或市场占有率。640px 及以下使用手机布局，较大屏幕沿用桌面导航和工作区。

## 界面约定

- **导航**：手机正文占满宽度，顶部按钮打开侧边抽屉。抽屉提供遮罩、关闭按钮、Escape 关闭、焦点循环和背景滚动锁定，选择页面后自动关闭。手机开关与桌面收起偏好分别管理，切换屏幕宽度不会覆盖桌面偏好。
- **内容**：手机统一使用 16px 页面边距、较紧凑的卡片内边距；首页统计和学习进度使用两列，首页奇数统计卡占满最后一行。表单输入使用 16px 字号，减少手机浏览器聚焦输入时的自动放大。
- **课次与资料**：日期与状态靠近课次标题，标题可换行；编辑、删除、替换等次要操作在手机收入“更多”，桌面直接显示同一份按钮。菜单支持外部点击、焦点离开和 Escape 关闭。上传、查看、下载和来源入口继续直接展示。
- **文字记录**：长标题与说话人管理分行；手机说话人编辑面板在卡片内展开，避免绝对定位跨出视口。扩大时间码、编辑和知识点操作的触控区。
- **弹窗与监控**：限制弹窗高度并允许内部滚动；文件预览关闭按钮不收缩或竖排。监控请求表在手机按带字段标签的卡片显示，直接提供详情入口。
