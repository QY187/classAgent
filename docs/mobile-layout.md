# 手机端布局

本轮以 390px 竖屏作为主要排版宽度，兼顾 360、375、414、430px；这些是测试视口宽度，不表示具体手机型号或市场占有率。640px 及以下使用手机布局，较大屏幕沿用桌面导航和工作区。

## 界面约定

- **导航**：手机正文占满宽度，顶部按钮打开侧边抽屉。抽屉提供遮罩、关闭按钮、Escape 关闭、焦点循环和背景滚动锁定，选择页面后自动关闭。手机开关与桌面收起偏好分别管理，切换屏幕宽度不会覆盖桌面偏好。
- **内容**：手机统一使用 16px 页面边距、较紧凑的卡片内边距；首页统计和学习进度使用两列，首页奇数统计卡占满最后一行。表单输入使用 16px 字号，减少手机浏览器聚焦输入时的自动放大。
- **课次与资料**：日期与状态靠近课次标题，标题可换行；编辑、删除、替换等次要操作在手机收入“更多”，桌面直接显示同一份按钮。菜单支持外部点击、焦点离开和 Escape 关闭。上传、查看、下载和来源入口继续直接展示。
- **文字记录**：长标题与说话人管理分行；手机说话人编辑面板在卡片内展开，避免绝对定位跨出视口。扩大时间码、编辑和知识点操作的触控区。
- **问答**：手机课程和对话目录默认折叠，左侧图标打开浮层，展开时不挤动消息区。对话顶部压缩为 60px 工具栏，范围说明和单行省略的标题居中间；右侧“···”提供修改标题、查看课程或本课纪要、归档和删除。修改标题时才展开编辑表单。消息区独立滚动，输入区固定在工作区底部。可视视口变化时更新工作区高度，输入草稿仍由原组件保存。自动滚动仅作用于消息区，避免带动整页。
- **回答表格**：Markdown 表格按行列渲染，保留表头与列对齐，内容继续由 React 转义。宽表仅在可聚焦的表格容器内横向滚动，不拉宽页面。此项不改变纪要 HTML 的过滤规则。
- **弹窗与监控**：限制弹窗高度并允许内部滚动；文件预览关闭按钮不收缩或竖排。监控请求表在手机按带字段标签的卡片显示，直接提供详情入口。

## 验证

2026-11-10 使用本地浏览器隔离数据检查：

- 22 个路由 × 360 / 375 / 390 / 414 / 430 / 1440px，共 132 项页面检查，覆盖登录、课程、课次、转写、纪要、知识点、小测、结果、进度、课件、问答、错题、待处理、搜索、回收站、设置、额度与监控。
- 新建、编辑、文件替换与预览、说话人管理、纪要编辑、知识点创建、额度明细、导航、账号、搜索、问答引用与监控详情共 14 个交互状态。
- 360 / 390 / 430px 下检查导航关闭与焦点、课程和资料菜单、弹窗边界、说话人完整显示、聊天目录与删除确认、输入区位置、缩短可视高度后草稿保留；另检查桌面偏好与宽度切换。
- 首页、知识点、错题、待处理、搜索、回收站和聊天共 7 个空状态。
- 前端单元测试 29 项，包括新增的表格结构、转义和缺失列检查；生产构建包含 TypeScript 校验。
- 问答紧凑顶部追加 360 / 390 / 430 / 495 / 640px × 主对话 / 课程 / 课次共 15 项检查，均无整页横向溢出，工具栏 60px，消息区从页面顶部 124px 处开始（含全局顶栏 64px）；验证目录浮层不挤动正文、菜单内重命名和取消、删除确认取消、空状态与桌面编辑入口。

检查不调用真实模型，也不保存、删除或上传真实业务数据。手机视口模拟不能替代 iOS Safari / Android 真机的软键盘、录音权限和 PDF 查看器验收。本轮未修改服务端接口、数据库或生产配置，未部署或推送。

常规检查命令（在 `apps/web` 目录执行）：

```sh
npm test
npm run build
```

后续新增页面需遵守：不保留常驻手机侧栏；主操作直接可见；次要操作集中；长文件名和标题可以换行或省略；表格自行滚动；弹窗完整留在可视区域内。
