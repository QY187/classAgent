# 课程打包导出

## 当前使用与上线状态（2026-11-25）

入口为 `/courses/{courseId}/export`。四类资料默认全选，沿用蓝/青绿/暖棕/灰蓝排版；先点击“查看实际 PDF”，再选择课程/课次及文档，在页面内翻页、适合宽度或缩放。桌面和手机统一使用 PDF.js 绘制真实后端 PDF，也可在新窗口打开。

预览和 ZIP 导出读取已保存资料，复用后端生成器，不调用模型；选择范围变更会清除旧预览，资料在两次请求之间被编辑时需重新预览。缺失内容、加载、失败和重试有独立提示。

导出、预览与稳定性修复已于 2026-11-22 上线，2026-11-25 发布继续保留。版本和当时公网验证范围见 [部署记录](production-deployment.md)。下方带日期的“本地待验收”“未推送/部署”和 iframe 描述保留开发经过，不代表当前阅读器或部署状态。

课程详情点击“导出课程”，选择整门课程或指定课次，下载ZIP资料包。默认全选四项：智能纪要、知识点、小测题目、文字记录，统一为PDF。可取消不需要的内容，至少保留一项。不包含原音频、上传课件、答案或解析。

ZIP根目录为`课程目录.pdf`，每个课次按课程顺序建立编号文件夹，内含选中的`智能纪要.pdf`、`知识点.pdf`、`小测题目.pdf`、`文字记录.pdf`。同名课次不覆盖；暂无内容也会在相应PDF中说明。保留保存的纪要修改、知识点掌握状态和来源、说话人及片段起止时间；小测仅包含题目与选项。跨课次或课程小测合并为`课程公共资料/小测题目.pdf`。导出不调用模型，不改变学习进度。

指定课次可搜索并追加选择，最多500节。仅收录范围完全落在所选课次内的小测，整门课程小测仅在全课程模式导出；回收站内容排除。课程为空时仅生成目录PDF。

已认证接口`POST /courses/{course_id}/export`，`lesson_ids=null`表示全课程，非空列表表示指定课次。可选`contents`仅接受`summaries`、`knowledge`、`quizzes`、`transcripts`四个布尔字段，默认全部true；旧附件、答案字段不再接受。

```json
{"lesson_ids": null, "contents": {"summaries": true, "knowledge": true, "quizzes": true, "transcripts": true}}
```

PDF为A4纵向，嵌入中文TrueType字体，带页眉页码；不加载外部图片或网页。Docker安装文泉驿正黑字体；非Docker运行可通过`PDF_CJK_FONT`指定兼容中文TrueType字体路径。依赖ReportLab与markdown-it-py。

导出校验课程归属和课次可见性，构建完成再次核对范围。ZIP在临时磁盘生成，完成、失败或响应中断后清理，不留永久副本。最多512MB、2000个文件，单份PDF最多200页，构建检查150秒预算；超过时提示分批。浏览器最长等待10分钟，可取消等待（不保证服务端立即停止构建）。

最初开发时仅更新本机；后续上线状态以上文和部署记录为准。

## PDF阅读版式优化（2026-11-22）

四类文档采用统一标题区、信息区、章节色带与页眉页脚：智能纪要为蓝色，知识点为青绿色，小测为暖棕色，文字记录为灰蓝色。课程目录沿用蓝色。标题保留完整内容，超长标题自动缩小并换行；课程、日期、状态等信息集中浅底展示，来源摘录与正文分开。

小测选项按A/B/C/D直接排版，常规短题与选项一起分页，超长题允许正常拆分；文字记录的片段时间、说话人与正文分层，中文全角标点避免落在行首。保留原文及不含答案的要求，不生成独立封面空页。

导出专项和排版测试共22项通过，实际只读接口导出四类PDF及目录，另生成多题、长标题、长纪要、长文字记录样本，共17页渲染检查。证据与四页预览位于忽略目录`test-results/pdf-layout-20261122/`。本轮仅改后端排版及类型传递，不涉及前端或数据库，未推送部署。

## 页面内PDF阅读器修复（2026-11-22，本地待验收）

桌面内嵌iframe依赖浏览器PDF插件，自动化和可视检查出现灰色区域、内容裁切，之前仅验证PDF有效与iframe存在不足以完成界面验收。现统一使用锁定版本PDF.js在页面内绘制真实PDF，桌面与手机均支持上一页、下一页、适合宽度和75%/125%/150%/200%缩放。放大后的滚动限制在阅读区；新文档重置到第一页并适配宽度。仍可在新窗口用原生阅读器进行文字选择、搜索与打印。

每次只绘制当前页，像素分配约8百万上限、高分屏倍率最高2；窗口尺寸变化自动重绘。切换页面/文档、收起和卸载时取消旧绘制并销毁PDF加载任务，避免旧页面覆盖新内容。加载与绘制失败显示提示；源文件加载失败的重试会重新请求后端PDF，避免重复解析同一损坏文件。

PDF.js Worker由锁定依赖复制至版本化的本地静态路径，开发启动和生产构建前自动生成，随public打包，不依赖CDN。生成文件不入Git。依赖安装在独立检出的node_modules，已移除原指向主工作区的目录联接，主工作区依赖不变。

## 普通滚动条下闪烁修复（2026-11-22，本地待验收）

用户反馈持续闪烁后，在保留普通滚动条的可视浏览器复现：7秒内808次DOM/加载状态变化，可用宽度在1023与1038像素之间往返。原实现绘制前清空Canvas，滚动条消失后增加15px宽度，ResizeObserver触发重绘；新Canvas插入后滚动条再次占位又缩小宽度，形成循环。此前无头浏览器隐藏滚动条，未覆盖此场景。

修复为阅读区始终保留纵向滚动条/稳定槽位，仅响应外部边框盒的实际宽度变化，并在新页离屏绘制完成后原子替换旧Canvas，不在绘制前清空。高度变化不会触发宽度重绘；真实窗口变化、缩放、翻页仍可正常更新。相同环境连续7秒记录变化为0。

新增可复用浏览器回归`apps/web/tests/pdf-preview-stability.test.mjs`，使用开发依赖playwright-core和本机已安装Edge（可通过`PDF_PREVIEW_BROWSER_CHANNEL`覆盖）。先启动独立预览样例，再在PowerShell执行：

```powershell
$env:PDF_PREVIEW_TEST_URL='http://127.0.0.1:3324'
node --test apps/web/tests/pdf-preview-stability.test.mjs
```

测试强制保留15px普通滚动条，验证390/1440宽度静置/滚动无Canvas替换或busy循环、重绘期间旧Canvas不被清空、缩放不撑宽整页、窗口变化后稳定和收起清理。需要其他固定样例时可配置`PDF_PREVIEW_TEST_COURSE`、`PDF_PREVIEW_TEST_TOKEN`、`PDF_PREVIEW_TEST_USER`。普通`npm test`未配置地址时明确跳过该浏览器专项；原42项单元测试通过，专项独立执行通过。

本次闪烁修复的最终生产构建/类型检查通过；360/390/1440四类文档、首尾页、缩放、切换、重试和真实ZIP下载再次通过，页面异常与失败资源均为0。主工作区证据`test-results/pdf-preview-review-20261122/flash-before.json`、`flash-after.json`及`flash-reader-results.json`记录复现和修复结果。仅本地预览分支，未推送或部署。
