# 课程打包导出

课程详情点击“导出课程”，选择整门课程或指定课次，下载ZIP资料包。默认全选四项：智能纪要、知识点、小测题目、文字记录，统一为PDF。可取消不需要的内容，至少保留一项。不包含原音频、上传课件、答案或解析。

ZIP根目录为`课程目录.pdf`，每个课次按课程顺序建立编号文件夹，内含选中的`智能纪要.pdf`、`知识点.pdf`、`小测题目.pdf`、`文字记录.pdf`。同名课次不覆盖；暂无内容也会在相应PDF中说明。保留保存的纪要修改、知识点掌握状态和来源、说话人及片段起止时间；小测仅包含题目与选项。跨课次或课程小测合并为`课程公共资料/小测题目.pdf`。导出不调用模型，不改变学习进度。

指定课次可搜索并追加选择，最多500节。仅收录范围完全落在所选课次内的小测，整门课程小测仅在全课程模式导出；回收站内容排除。课程为空时仅生成目录PDF。

已认证接口`POST /courses/{course_id}/export`，`lesson_ids=null`表示全课程，非空列表表示指定课次。可选`contents`仅接受`summaries`、`knowledge`、`quizzes`、`transcripts`四个布尔字段，默认全部true；旧附件、答案字段不再接受。

```json
{"lesson_ids": null, "contents": {"summaries": true, "knowledge": true, "quizzes": true, "transcripts": true}}
```

PDF为A4纵向，嵌入中文TrueType字体，带页眉页码；不加载外部图片或网页。Docker安装文泉驿正黑字体；非Docker运行可通过`PDF_CJK_FONT`指定兼容中文TrueType字体路径。依赖ReportLab与markdown-it-py。

导出校验课程归属和课次可见性，构建完成再次核对范围。ZIP在临时磁盘生成，完成、失败或响应中断后清理，不留永久副本。最多512MB、2000个文件，单份PDF最多200页，构建检查150秒预算；超过时提示分批。浏览器最长等待10分钟，可取消等待（不保证服务端立即停止构建）。

本轮只更新本机，未推送或部署。

## PDF阅读版式优化（2026-11-22）

四类文档采用统一标题区、信息区、章节色带与页眉页脚：智能纪要为蓝色，知识点为青绿色，小测为暖棕色，文字记录为灰蓝色。课程目录沿用蓝色。标题保留完整内容，超长标题自动缩小并换行；课程、日期、状态等信息集中浅底展示，来源摘录与正文分开。

小测选项按A/B/C/D直接排版，常规短题与选项一起分页，超长题允许正常拆分；文字记录的片段时间、说话人与正文分层，中文全角标点避免落在行首。保留原文及不含答案的要求，不生成独立封面空页。

导出专项和排版测试共22项通过，实际只读接口导出四类PDF及目录，另生成多题、长标题、长纪要、长文字记录样本，共17页渲染检查。证据与四页预览位于忽略目录`test-results/pdf-layout-20261122/`。本轮仅改后端排版及类型传递，不涉及前端或数据库，未推送部署。


## 下载前PDF预览（2026-11-22，本地待验收）

导出页增加“查看实际 PDF”。先选择课程目录、具体课次或课程公共资料，再切换已勾选的文档。预览读取真实已保存资料，与最终ZIP复用同一内容组装、四类配色和ReportLab渲染器；不会调用模型或修改学习数据。缺少内容仍生成说明PDF。预览与下载分别读取当前保存版本，期间修改资料时需重新打开预览，不承诺两个时间点的快照完全一致。

新增已认证 `POST /courses/{course_id}/export/preview`，请求体与导出一致。不带查询参数返回 `documents` 文档名数组（目录优先）；`?document=<完整文档名>` 返回 `application/pdf`、`Content-Disposition: inline`。文档名只匹配当前授权归档条目，不作为磁盘路径；未选内容、未选课次、回收站课次和他人课程不能预览。沿用构建前后范围核对、文件数/体积/页数/耗时限制及临时文件清理。枚举不渲染PDF，单文档请求只渲染目标PDF，响应不缓存。

桌面内嵌浏览器PDF阅读器，手机通过“在新窗口打开 PDF”使用原生阅读器；桌面也保留该入口。正在加载、超时、缺失资料、服务失败分别提示，失败可以重新加载。调整范围或内容会清除旧预览；切换、收起及离开页面中止客户端等待并释放Blob URL。取消不保证立即停止服务端构建。
