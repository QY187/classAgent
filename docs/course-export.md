# 课程打包导出

课程详情页点击“导出课程”，选择整门课程或指定课次，下载ZIP。指定课次可以搜索并追加选择，搜索不清空已选项，最多选500节；全课程按当前可见课次打包。导出沿用课程页面的排序。

资料包包含根目录的`课程目录.md`及按序号/标题命名的课次文件夹。每个课次内有`智能纪要.md`与`文字记录.txt`；同名课次不会互相覆盖。目录提供相对链接和内容状态，缺少纪要或转写时明确说明。保留当前已保存的结构化纪要或手动编辑内容、说话人名称和片段起止时间。导出不会重新生成内容或调用模型。

接口为已认证的`POST /courses/{course_id}/export`，`lesson_ids=null`代表全课程，非空列表代表指定课次。禁止导出他人课程、外课程课次和回收站内容；构建结束前再次核对范围。ZIP在临时磁盘构建，响应后及失败/中断时清理，不保存永久副本。单次最多512MB原始内容、2000个文件，构建检查150秒预算，超出时提示分批导出。

本轮为本地实现，未推送或部署。
