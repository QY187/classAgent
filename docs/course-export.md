# 课程打包导出

课程详情页点击“导出课程”，选择整门课程或指定课次，下载ZIP。指定课次可以搜索并追加选择，搜索不清空已选项，最多选500节；全课程按当前可见课次打包。导出沿用课程页面的排序。

资料包包含根目录的`课程目录.md`及按序号/标题命名的课次文件夹。每个课次内有`智能纪要.md`与`文字记录.txt`；同名课次不会互相覆盖。目录提供相对链接和内容状态，缺少纪要或转写时明确说明。保留当前已保存的结构化纪要或手动编辑内容、说话人名称和片段起止时间。导出不会重新生成内容或调用模型。

接口为已认证的`POST /courses/{course_id}/export`，`lesson_ids=null`代表全课程，非空列表代表指定课次。禁止导出他人课程、外课程课次和回收站内容；构建结束前再次核对范围。ZIP在临时磁盘构建，响应后及失败/中断时清理，不保存永久副本。单次最多512MB原始内容、2000个文件，构建检查150秒预算，超出时提示分批导出。

本轮为本地实现，未推送或部署。

## 可选导出内容

默认只勾选智能纪要与文字记录。还可单独选择：

- 知识点：Markdown，包含标题、正文、卡片类型、掌握状态与已保存的来源摘录。
- 小测题目：Markdown，默认练习版；勾选“附参考答案与解析”后才附标准答案、解析和出题时来源摘录。导出不改变题组状态、作答记录或学习进度。参考答案属于已认证课程所有者明确选择的导出内容；原作答接口仍在提交前隐藏答案。
- 原音频：保存课次关联的原始音频文件，不转码。
- 上传课件：保存原始文件，包含所选课次课件与课程公共课件，不要求课件已经解析。

接口在原参数上增加可选`contents`对象：`summaries`、`transcripts`默认为true；`knowledge`、`quizzes`、`answers`、`audio`、`materials`默认为false。至少选择一种实际内容；`answers=true`要求`quizzes=true`。仅改变内容勾选时不改变课次选择。

```json
{
  "lesson_ids": ["课次ID"],
  "contents": {
    "summaries": true,
    "transcripts": true,
    "knowledge": true,
    "quizzes": true,
    "answers": false,
    "audio": false,
    "materials": true
  }
}
```

指定课次仅收录范围完全在所选课次中的单课次/多课次小测；整门课程小测仅在全课程模式导出，涉及回收站课次的小测会被排除。跨课次和课程小测放在`课程公共资料/小测/`；课程公共课件放在`课程公共资料/上传课件/`。课次原文件按序号命名以避免同名覆盖，并保留扩展名。若某课次在勾选内容中没有文件，会提供课次说明；原文件缺失会在根目录列出，不伪造成功文件。文件读取中途失败时整包失败并清理临时ZIP。

原文件从本地存储或S3分块写入ZIP，不整批加载到内存或额外复制到临时文件；输出字节持续计入体积上限，附件声明体积超限会在读取前拒绝。S3响应及本地文件在成功/失败时关闭。浏览器允许等待下载最多10分钟，用户可取消等待后调整选项；取消等待不保证服务器立即停止已开始的打包，但响应结束或中断后会清理临时ZIP。
