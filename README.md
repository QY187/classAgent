# ClassAgent

ClassAgent 是面向学生的课堂学习助手：按课程和课次保存录音、文字记录、纪要和课件，结合有来源的问答、知识点、小测与课程表，支持课后回顾和复习。

当前已提供可运行的 Web 应用，正式入口为 [njust.shop](https://njust.shop)。截至 2026-11-25，问答记忆、课程表与课表 OCR 等更新已部署；本次按用户要求只做启动、健康和运行状态检查，未做线上业务验收。具体版本、验证范围与回退信息见 [生产部署记录](docs/开发与部署/003-production-deployment.md)。

## 已实现的功能

日常使用可以沿着这条路径进行：建立课程与课次 → 录音或上传音频/课件 → 校对文字记录和纪要 → 提问、整理知识点或生成小测 → 查看错题与学习统计 → 预览并导出课程资料。课程表用于安排上课时间，与课程资料关联管理。

### 1. 课程、课次与首页

按课程组织课次和公共资料，支持创建、改名、修改学期或课次日期；课次可以手动拖动排序。课程公共课件与某一课次的课件分别归档，避免把公共资料错误归到一次课堂记录。

首页显示本周课程表、今日课程、课程总数、待处理课次和最近学习。待处理列表能查看转写或纪要的实际状态、失败原因并进入对应课次；最近学习来自真实提问、作答或知识点标记，不代表学习时长或掌握程度。课程、课次、附件可以进入回收站恢复，默认保留 30 天，到期由后台清理。

### 2. 录音、文字记录与智能纪要

- 在课次工作台使用浏览器录音，或上传已有音频。浏览器尝试实时识别；没有已确认文字或直接上传文件时，后台调用百炼文件转写。麦克风权限、浏览器能力和识别网络会影响实时文字，音频与文字的状态分别展示。
- 文字记录按片段保存时间范围和说话人标签，可以人工修改、合并片段、重命名说话人，并定位到录音时间点回听。支持收藏或标记“没听懂”的片段；说话人标签不等于已可靠识别真实姓名。
- 智能纪要根据已保存文字生成，可查看、编辑、重新生成并核对引用。已手动编辑内容按保存版本展示和导出；主动重新生成会覆盖这些修改，页面会提示。
- 转写和纪要具有排队、处理中、完成或失败等状态。保存音频、转写和生成是不同步骤，上传成功不等于全部处理完成。

使用方式与来源边界见 [录音、转写与纪要](docs/纪要与转写/002-recordings-and-summaries.md)。

### 3. 课件管理与全局搜索

课程公共资料和课次资料支持上传、预览、下载、删除及替换。文字型 PDF、PPTX、DOCX、TXT、Markdown 可以后台提取正文，建立切片与向量，供搜索、问答和课件出题使用；旧资料可手动加入问答。

替换文件采用暂存解析后再发布的方式：新版本失败时保留当前可用版本，成功后更新原件、切片与索引。课件引用可定位到文件、PDF 页码、幻灯片或段落；来源已替换、删除或不可访问时会标明变化，而不是继续使用旧位置。

全局搜索支持输入后自动查询、中文简写及空格分隔的多个关键词，可以按课程和内容类型筛选。搜索范围包括课程、课次、文字记录、纪要、知识点与课件正文；文字结果能跳到课堂时间点，课件结果能查看提取原文。搜索失败提供重试，不以空列表冒充失败结果。

### 4. 问答工作台与 Agent

主对话可以查询当前账号下的可见课程，整门课程对话限定为绑定课程；已有课次对话仍保留本课次范围。支持多个独立对话、连续追问、改名、搜索、归档、删除、停止生成和失败后重试，聊天模型按对话保存选择。

Agent 可以查询课程、课次、纪要、课堂原文、课件、学习统计与待处理事项，并在明确委托时执行已接入的课程/课次管理、知识点状态修改、小测生成等受控操作。缺少参数或目标不唯一时先澄清，后端检查归属和操作范围，结果以实际业务回执为准。

回答采用流式展示，保留工具执行记录、来源引用及请求详情。资料不足、没有匹配内容、额度不足和执行失败分别说明；可复制回答或附带来源复制。历史回答和模型生成的叙述不能代替本轮实际查到的课堂证据，也不能自动授权新的写操作。

### 5. 上下文压缩与可管理记忆

默认为对话记忆分配约 16000 个估算 Token，达到可用预算约 80% 时，在模型规划前压缩较早的完整问答，并保留检查点和近期原文。压缩保存带消息出处的关键摘录，原聊天记录仍保留；压缩失败且仍超预算时暂停本轮并提示重试，不把未处理前缀静默丢掉后继续作答。

历史召回结合按权限过滤的关键词检索和可用时的向量检索；向量服务不可用时可以降级。长期偏好通过记忆管理页或“记住：内容”等明确命令保存，可以编辑、删除及查看来源；不会从普通聊天自动构建用户画像。

`/memories` 提供历史与长期记忆开关，聊天可切换临时模式。临时模式停止摘要、跨会话召回和长期记忆读写，但仍保存聊天并保留预算内的当前对话近期交流。记忆不保证逐字记住所有历史，也不会替代课堂原文或新的操作授权。

### 6. 知识点、小测、错题与学习统计

- 知识点卡片可从纪要中的有效课堂来源生成，也可手动维护。按课程和“未学习 / 需要复习 / 已掌握”筛选，状态由用户标记，不自动安排到期复习或推断能力。
- 课程小测支持课堂记录或已解析课件来源，可选择整门课程、指定课次或课件，设置 5/10/15 道及单选/判断题型。有效内容不足时可能返回较少题或明确失败，不承诺凑满题数。
- 作答前隐藏答案，提交后查看判分、解析及来源。错题本支持课程/巩固状态筛选、连续逐题重练和本轮汇总，已提交结果保存；课件错题可重练，但不会伪装成依赖课堂片段的知识点卡片。
- 课程进度汇总课次、文字记录、可用纪要、知识点状态和小测统计，小测可按北京时间作答日期筛选。统计反映实际记录，不等于学习时长或自动掌握程度评估。

### 7. 学期课程表与课表导入

设置学期起始日期、周数和节次，管理教师、教室、关联课程、星期、起止小节和单双周。首页与课程表支持周次下拉直达、上一周/下一周、回到本周，以及重叠课程卡片的展开和切换；今日课程依据实际当前周计算。

导入支持文字 PDF、扫描 PDF、CSV 和旧版 XLS。先解析预览，逐条校对和勾选，再确认写入；重复排课跳过，冲突导致整批回滚。扫描课表使用本地 RapidOCR，不调用外部大模型；限制 8 MiB、15 页 PDF（扫描页最多 5 页）、300 条候选，OCR 单次最长 120 秒。

课表 OCR 仅服务于课表导入，不代表普通扫描课件也能参与 OCR 问答。模糊、倾斜或复杂版式仍可能识别错误，必须人工核对后导入。

### 8. 导出、账号与运行管理

整门课程或指定课次可以将智能纪要、知识点、小测题目、文字记录统一导出为 PDF ZIP，四项默认全选；包含课程目录，缺失内容有说明，不附原音频、课件、答案或解析。四类 PDF 保留蓝、青绿、暖棕和灰蓝版式，下载前可在桌面或手机查看真实 PDF、翻页、适合宽度和缩放。预览与下载复用后端生成器，读取已保存资料，不调用模型。

个人设置支持头像和密码管理，后端按当前用户隔离课程、资料与对话。Token 页面显示每日额度、已用、预留和可用量，管理员可调整用户额度、查询计量；运行监控提供请求追踪、工具和模型阶段等信息，按权限展示。模型凭据只在服务端配置，页面选择已开放的模型编号。

## 本地快速启动

需要 Docker Desktop（Linux 引擎）、Node.js 22 和 npm。默认由 Docker 运行后端与依赖，前端由本机 Node.js 启动；不需要从 IDEA 单独运行后端，也不要求本机安装 Python、PostgreSQL 或 Redis。

在仓库根目录按需建立本地 `.env`，配置服务端模型凭据及管理员配置，详见 [本地开发说明](docs/开发与部署/001-local-development.md)。未配置模型凭据也可启动页面、管理资料、预览导出和使用本地课表 OCR；转写、生成与向量调用需要各自有效配置。

```powershell
docker compose up --build -d
docker compose ps
Invoke-RestMethod http://localhost:8000/health
```

另开终端：

```powershell
Set-Location apps/web
npm ci
npm run dev
```

打开 [本地前端](http://localhost:3000)；后端接口说明位于 [API Docs](http://localhost:8000/docs)。首次构建包含 LibreOffice、中文字体和 OCR 依赖，下载较大；后续依赖不变时复用镜像和缓存。修改后端依赖后需重建 `api`、`worker`、`beat`，仅重新启动旧镜像不能安装新增依赖。

| 服务 | 职责 |
| --- | --- |
| PostgreSQL + pgvector | 保存账号、课程、学习记录、记忆与向量索引 |
| Redis | Celery 消息队列及任务结果；也用于令牌与会话控制，不只是缓存 |
| API | 鉴权、业务接口、资料读写及任务投递 |
| Worker | 消费队列，执行转写、纪要、资料索引和记忆后台任务 |
| Beat | 定时投递转写补偿、索引补偿和回收站清理任务；不负责从 Redis 取任务交给 Worker |
| 本机 Next.js | 提供开发前端；生产环境前端也运行于 Docker |

正常任务在业务请求中直接尝试投递，Beat 用于定时补偿和清理，不是上传后必须等待的正常入口。服务日志、配置、停止与数据保留方法见 [本地开发说明](docs/开发与部署/001-local-development.md)。

## 配置与能力边界

- 浏览器通过 MediaRecorder 录音，并尝试浏览器语音识别；浏览器识别可用性取决于浏览器、权限与网络。直接上传音频，或录音未获得已确认文字时，后台使用百炼文件转写，需要 `DASHSCOPE_API_KEY`。
- 默认纪要使用 DeepSeek，需要 `DEEPSEEK_API_KEY`。Agent 可通过 `AGENT_*` 与 `AGENT_MODELS` 配置兼容模型，聊天只选择服务端允许的模型编号；详见 [多模型说明](docs/问答与Agent/014-agent-models.md)。
- 文本向量默认使用百炼 `text-embedding-v2`，向量列固定 1536 维。改变模型或维度前需规划迁移；不要直接切换配置后沿用旧索引。
- 记忆默认预算 `MEMORY_CONTEXT_BUDGET=16000` 是应用估算预算，约在可用预算的 80% 触发压缩，不是模型完整上下文窗口。详见 [记忆机制](docs/问答与Agent/015-agent-memory.md)。
- 开发 Compose 默认将音频及附件保存于持久卷，不依赖 MinIO；生产当前也使用本地持久卷，可按需配置 S3 兼容存储。不要用本地 `.env` 覆盖生产配置。
- 来源缺失、资料不足与执行失败分别提示；模型生成的纪要、答案和题目仍应核对。课表 OCR 必须校对后导入。待办与疑问模块、学习时长统计、自动掌握程度推断尚未实现。
